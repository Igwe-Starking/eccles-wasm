# Quick Start

Three steps: run it on your PC, run it on your board, write your own module. Nothing here needs special hardware for step 1.

## 1. Run it on your PC (2 minutes)

You need `git`, `make` and a C compiler (`gcc` or `clang`).

```bash
git clone https://github.com/igwe-starking/eccles-wasm
cd eccles-wasm
make examples
build/example_host examples/blink.wasm
```

You see the module blink a pin and print, on a simulated chip. If that works, the runtime is fine on your machine.

## 2. Compile your first module

A module is a normal C program compiled with `clang` for the `wasm32` target. Install clang and `wasm-ld` (`sudo apt install clang lld` on Debian/Ubuntu, `brew install llvm lld` on macOS).

```c
/* hello.c - the smallest useful guest: one function that computes, one that prints. */
#include "eccles_wasm_runtime.h"

EW_EXPORT("add") int add(int a, int b) { return a + b; }

EW_EXPORT("fib") int fib(int n) {
    int a = 0, b = 1;
    while (n-- > 0) { int t = a + b; a = b; b = t; }
    return a;
}

EW_EXPORT("hello") void hello(void) {
    ew_printf("hello from wasm, running for %u ms\n", (unsigned)ew_millis());
}
```
*(file: `examples/wiki/guest/hello.c`)*

Build it:

```bash
clang --target=wasm32 -O2 -nostdlib -ffreestanding \
  -Wl,--no-entry -Wl,--export-all -Wl,-z,stack-size=4096 -Wl,--initial-memory=65536 \
  -Isdk/c -o hello.wasm hello.c
```

## 3. Run it from C

```c
/* 01_hello.c - load a module, call its functions, handle errors. */
#include "eccles_wasm.h"
#include <stdio.h>

int main(int argc, char **argv) {
    const char *path = argc > 1 ? argv[1] : "build/wiki/hello.wasm";

    eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_SAFE);        /* hello() prints and reads the clock: LOG + TIME */

    if (eccles_wasm_load(path) != ECCLES_WASM_SUCCESSFUL) {         /* 1. load */
        printf("load failed: %s (info %u)\n",
               eccles_wasm_error_name(eccles_wasm_last_error()),
               (unsigned)eccles_wasm_last_error_info());
        return 1;
    }

    uint64_t args[2] = { eccles_wasm_from_i32(20), eccles_wasm_from_i32(22) };
    uint64_t result[1];
    if (eccles_wasm_call("add", args, 2, result, 1) == ECCLES_WASM_SUCCESSFUL)   /* 2. call with arguments */
        printf("add(20, 22) = %d\n", (int)eccles_wasm_to_i32(result[0]));

    args[0] = eccles_wasm_from_i32(10);
    if (eccles_wasm_call("fib", args, 1, result, 1) == ECCLES_WASM_SUCCESSFUL)
        printf("fib(10)     = %d\n", (int)eccles_wasm_to_i32(result[0]));

    eccles_wasm_run("hello");                                       /* 3. call with no arguments */

    if (!eccles_wasm_has_export("nope"))                            /* 4. ask before you call */
        printf("no export called \"nope\" - that is fine\n");

    eccles_wasm_stats_t s = eccles_wasm_get_stats();                /* 5. how much memory did that take? */
    printf("arena: %u bytes, module loaded: %s\n", (unsigned)s.arena_size, s.loaded ? "yes" : "no");
    return 0;
}
```
*(file: `examples/wiki/host/01_hello.c`)*

Build and run:

```bash
gcc -std=c99 -O2 -Isrc examples/wiki/host/01_hello.c src/eccles_wasm.c -o hello_host -lm
./hello_host hello.wasm
```

Output:

```text
add(20, 22) = 42
fib(10)     = 55
hello from wasm, running for 0 ms
no export called "nope" - that is fine
arena: 1046784 bytes, module loaded: yes
```

(On the desktop simulator the clock is virtual, so `running for 0 ms` is expected. On a chip it shows real time.)

## 4. Put it on a board

1. Pick your platform page: [Arduino](Platform-Arduino), [ESP-IDF](Platform-ESP-IDF), [Pico](Platform-Raspberry-Pi-Pico), [STM32](Platform-STM32), [Zephyr/nRF](Platform-Zephyr-and-nRF), [any other chip](Platform-Other-MCUs).
2. Embed `hello.wasm` as a C array: `python3 tools/wasm2c.py hello.wasm hello_wasm.h hello_wasm`
3. Call `eccles_wasm_set_hal_privilege(...)`, then `eccles_wasm_load_buffer(hello_wasm, hello_wasm_len)`, then `eccles_wasm_call(...)`.

## The four lines that matter

```c
eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_SAFE);              // 1. what the module may touch (nothing by default)
eccles_wasm_load_buffer(app_wasm, app_wasm_len);                    // 2. load
eccles_wasm_run("setup");                                           // 3. run an export
eccles_wasm_call("add", args, 2, result, 1);                        // 4. call with arguments, get a result
```

If a module does nothing and returns status 3, you forgot line 1. See [Permissions](Permissions).

# Concepts

Eight ideas. Read this once and the rest of the wiki is easy.

## Host and guest

- The **host** is your firmware: C code that includes `eccles_wasm.h` and links `eccles_wasm.c`.
- The **guest** (also called module) is a `.wasm` file the host loads and runs. It is compiled from C, C++ or Rust on your PC.

The guest can only compute, and call functions the host allows. It cannot touch memory outside its own sandbox.

```
  your PC                      your microcontroller
 ┌──────────┐   app.wasm   ┌──────────────────────────────┐
 │ clang    │ ───────────► │ host firmware                │
 │ (guest.c)│  (file, OTA, │   eccles_wasm.c  ◄── you call │
 └──────────┘   flash)     │   ┌────────────────────────┐ │
                           │   │ guest sandbox (arena)  │ │
                           │   └─────────┬──────────────┘ │
                           │             ▼ imports        │
                           │   GPIO · ADC · I2C · SPI ... │
                           └──────────────────────────────┘
```

## The arena

All memory the runtime uses comes from one block, the **arena** (`ECCLES_WASM_ARENA_SIZE`): the module's metadata, the translated code, the stacks and the guest's linear memory. There is no `malloc` inside the interpreter. When the arena is too small, loading fails with `no memory` and `last_error_info()` tells you how many bytes were needed. See [Memory Sizing](Memory-Sizing).

## Load, then call

1. `eccles_wasm_load*` reads the module in small chunks (256 bytes by default), validates it, and translates it. A module is never held in RAM whole.
2. `eccles_wasm_call("name", ...)` runs an exported function and returns the results.

## Status codes

Every hardware call returns one of four numbers. The same numbers are visible inside the guest.

| Value | Name | Meaning |
|---|---|---|
| 0 | SUCCESSFUL | it worked |
| 1 | FAILED | tried and failed (bad pin, bus error, a trap) |
| 2 | UNSUPPORTED | this chip or backend cannot do it |
| 3 | DENIED | the host did not grant this module that hardware |

For the reason behind a FAILED result use `eccles_wasm_last_error()`. See [Error Reference](Error-Reference).

## Permissions (deny by default)

A new module can compute and nothing else. You grant hardware with `eccles_wasm_set_hal_privilege(bits)`, and you can limit it to specific pins, buses and I2C addresses. A refused call returns 3 to the guest and does not touch the hardware. See [Permissions](Permissions).

## Safety

- **Sandbox:** every memory access is bounds-checked. A wild pointer traps, it does not corrupt your firmware.
- **Fuel:** an instruction budget stops endless loops.
- **Traps:** any fault ends the call with an error code. The instance stays usable.

See [Safety, Fuel and Traps](Safety-Fuel-and-Traps).

## Two ways to structure a module

**`setup` and `loop` (the default).** The module exports `setup` and `loop`. The host calls `setup` once, then calls `loop` over and over:

```c
eccles_wasm_run("setup");
for (;;) { eccles_wasm_run("loop"); /* your firmware can do other work here */ }
```

The host gets control back between iterations. It can feed a watchdog, service WiFi or BLE, check for a new module, swap modules, or stop the module whenever it likes. Each call is one bounded piece of work, so a fuel budget per call works naturally.

**`main` (one call, the module loops inside).** For a dedicated device where the module is the whole program, export a single `main` and loop inside it:

```c
EW_EXPORT("main") void app_main(void) {
    ew_enable(2);                       // setup
    for (;;) { ew_toggle(2); ew_sleep(500); }
}
```

```c
eccles_wasm_run("main");                // one call; the module runs
```

What you gain: no host-to-WebAssembly call per iteration, and state stays in local variables instead of globals. What to remember:

- `eccles_wasm_run("main")` **blocks** while the module loops. Run it in its own task, or put it last in your start-up code.
- Fuel is per call, so leave `eccles_wasm_set_fuel(0)` (the default) for a `main` that never returns.
- Always sleep or wait inside the loop (`ew_sleep`). A loop that never sleeps starves the idle task and the watchdog.
- To stop it from the host, give the module a stop flag ([Cookbook](Cookbook#stop-or-swap-a-running-main)).

Rule of thumb: start with `setup` and `loop`. Move to `main` when the host has nothing else to do, or when the loop is so tight that the per-call overhead matters.

## Instances

`eccles_wasm_load()` and friends use a built-in default instance. For several modules at once, create more instances with `eccles_wasm_vm_create()`. Each has its own arena, privileges and host functions. See [Instances](Instances).

## Optional extras

| Feature | Switch | You provide |
|---|---|---|
| Threads | `ECCLES_WASM_ATOMICS=1`, `ECCLES_WASM_THREADS=1` | a **spawner** (creates the RTOS task) |
| Loading from your own file system | none | `eccles_wasm_set_fs(open, read, close)` |
| Another chip | none | `eccles_wasm_hal_override(&ops)` |
| Fastest loop | `ECCLES_WASM_EXEC_IRAM=1`, `ECCLES_WASM_FUEL=0` | nothing |

# Install

The library is two files, `src/eccles_wasm.h` and `src/eccles_wasm.c`, plus an optional `eccles_wasm_config.h`. Pick the section for your toolchain.

## Arduino IDE

1. Download the repository as a ZIP from GitHub (green **Code** button, **Download ZIP**).
2. Arduino IDE: **Sketch, Include Library, Add .ZIP Library**, choose the ZIP.
3. Include it: `#include <eccles_wasm.h>`
4. To change settings, copy `config/eccles_wasm_config.h` into the installed library's `src/` folder (`Documents/Arduino/libraries/eccles-wasm/src/`) and uncomment what you need.

## PlatformIO

`platformio.ini`:

```ini
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
lib_deps = https://github.com/igwe-starking/eccles-wasm.git
build_flags =
    -DECCLES_WASM_ARENA_SIZE=98304ul
```

`build_flags` with `-D` is the most reliable way to configure the library: the sketch and the library both see the same macros. For ESP-IDF projects in PlatformIO use `framework = espidf` and see [ESP-IDF](Platform-ESP-IDF).

## ESP-IDF component

Either copy the folder into `components/eccles-wasm/`, or add it as a git dependency in your project's `main/idf_component.yml`:

```yaml
dependencies:
  eccles-wasm:
    git: https://github.com/igwe-starking/eccles-wasm.git
```

The component's `CMakeLists.txt` already exports `src` and `config`.

## CMake (any chip)

```cmake
add_subdirectory(eccles-wasm)                       # defines the target eccles_wasm
target_link_libraries(my_firmware PRIVATE eccles::wasm)
```

## Pico SDK

```cmake
add_executable(app main.c eccles-wasm/src/eccles_wasm.c)
target_include_directories(app PRIVATE eccles-wasm/src)
target_link_libraries(app pico_stdlib hardware_gpio hardware_adc hardware_pwm hardware_i2c hardware_spi hardware_uart hardware_watchdog pico_rand)
```

## STM32CubeIDE / Keil / IAR / any IDE

Copy `src/eccles_wasm.c` and `src/eccles_wasm.h` into your project, add the folder to the include path, and make sure the `.c` file is compiled as C99 or later. See [STM32](Platform-STM32).

## Zephyr / nRF Connect SDK

```cmake
target_sources(app PRIVATE src/main.c ../eccles-wasm/src/eccles_wasm.c)
target_include_directories(app PRIVATE ../eccles-wasm/src)
```

See [Zephyr and nRF](Platform-Zephyr-and-nRF).

## Plain `make` / `gcc` (PC, Linux, Raspberry Pi)

```bash
gcc -std=c99 -O2 -Isrc your_main.c src/eccles_wasm.c -o app -lm
```

## Settings: three ways, pick one

1. **Compiler flag** (recommended): `-DECCLES_WASM_ARENA_SIZE=98304ul`
2. **Config file:** copy `config/eccles_wasm_config.h` next to `eccles_wasm.h` and uncomment lines. Both `eccles_wasm.c` and your code pick it up automatically when it is on the include path.
3. **Edit nothing:** the defaults work on desktop and ESP32-class chips.

Both `eccles_wasm.c` and any file that includes `eccles_wasm.h` must see the **same** settings. A mismatch gives confusing crashes. Full list: [Configuration Reference](Configuration-Reference).

## The guest toolchain (on your PC, not the chip)

```bash
sudo apt install clang lld        # Linux
brew install llvm lld             # macOS
```

Check: `clang --target=wasm32 --version` and `wasm-ld --version`. For Rust: `rustup target add wasm32-unknown-unknown`. See [Writing Guests](Writing-Guests).

# Platforms Overview

Eccles WASM has a built-in hardware backend for six targets. A chip not listed still runs it: you supply the few hardware functions it needs ([Other MCUs](Platform-Other-MCUs)).

## What each backend can do

`yes` = built in. `glue` = a one-line helper or HAL override connects it (see the platform page). `no` = returns UNSUPPORTED unless you add it with `eccles_wasm_hal_override()`.

| Feature (guest import) | Desktop sim | Arduino | ESP-IDF | Pico SDK | STM32 HAL | Zephyr / nRF |
|---|---|---|---|---|---|---|
| GPIO: `mode` `read` `write` `enable` `disable` `toggle` | yes | yes | yes | yes | yes | yes |
| `analog` (PWM duty) | yes | yes | yes | yes | no | no |
| `pwm` (frequency + duty) | yes | no | yes | yes | no | no |
| `adc` | yes | yes | yes | yes | no | no |
| `dac` | no | no | no | no | no | no |
| `millis` `micros` `sleep` `sleep_us` `yield` | yes | yes | yes | yes | yes | yes |
| `random` | yes | ESP32 | yes | yes | no | yes |
| `reset` | yes | ESP32, Cortex-M | yes | yes | yes | yes |
| `deep_sleep` | yes | ESP32 | yes | no | no | no |
| `wdt_feed` | yes | no | yes | yes | no | no |
| `log` (console) | yes | glue | yes | yes | no | yes |
| `irq_*` (pin edge counters) | yes | no | yes | yes | no | no |
| `uart_*` | yes | glue | yes | yes | handles | no |
| `i2c_*` | yes | glue | yes | yes | handles | no |
| `spi_*` | yes | glue | yes | yes | handles | no |

"glue" on Arduino: `eccles_wasm_use_serial(Serial)`, `eccles_wasm_use_wire(Wire)`, `eccles_wasm_use_spi(SPI)`, `eccles_wasm_use_uart(Serial1, 1)`.
"handles" on STM32: list your CubeMX handles in the config file (`ECCLES_WASM_STM32_UART_HANDLES` etc).

A UNSUPPORTED result is not an error in your firmware. The guest receives status 2 and can adapt. Write the missing piece once with `eccles_wasm_hal_override()` and it works everywhere.

## Pin numbering

The number a guest passes as `pin` depends on the platform:

| Platform | Pin number | Example |
|---|---|---|
| Arduino | what `pinMode()` takes | `2`, `A0` is its numeric value |
| ESP-IDF | GPIO number | GPIO2 = `2` |
| Pico SDK | GP number | GP25 = `25` |
| STM32 HAL | `port * 16 + bit` | PA5 = `5`, PB0 = `16`, PC13 = `45` |
| Zephyr / nRF | `port * 32 + bit` | P0.13 = `13`, P1.08 = `40` |

Other numbers that differ by platform:

| | ADC pins | I2C buses | SPI buses | UART ports |
|---|---|---|---|---|
| ESP-IDF | ADC-capable GPIOs | by `I2C_NUM_MAX` | 0 = SPI2, 1 = SPI3 | by `UART_NUM_MAX` |
| Pico | 26 to 29 | 0, 1 | 0, 1 | 0, 1 |
| STM32 | n/a | index in your handle list | index in your handle list | index in your handle list |

## Which one do I use?

| I have | Use | Page |
|---|---|---|
| ESP32 / S2 / S3 / C3 with Arduino | Arduino backend | [Arduino](Platform-Arduino) |
| ESP32 family with ESP-IDF | ESP-IDF backend (most features) | [ESP-IDF](Platform-ESP-IDF) |
| Raspberry Pi Pico / Pico W / RP2040 / RP2350 | Pico backend | [Pico](Platform-Raspberry-Pi-Pico) |
| any STM32 | STM32 HAL backend | [STM32](Platform-STM32) |
| nRF52 / nRF53 / nRF91 / any Zephyr board | Zephyr backend | [Zephyr and nRF](Platform-Zephyr-and-nRF) |
| Arduino Nano 33 BLE, Uno R4, Teensy, SAMD, other Arduino cores | Arduino backend | [Arduino](Platform-Arduino) |
| RISC-V, MSP430, PIC, AVR, anything else | `PLAT_NONE` + HAL override | [Other MCUs](Platform-Other-MCUs) |
| a PC | host simulator | [Desktop Simulator](Platform-Desktop-Simulator) |

The backend is chosen automatically from your compiler's defines. Force one with `-DECCLES_WASM_PLATFORM=ECCLES_WASM_PLAT_ESP_IDF` (also `_ARDUINO`, `_PICO`, `_STM32_HAL`, `_ZEPHYR`, `_HOST`, `_NONE`).

## How much RAM and flash

- **Flash:** about 50 KB of code with `-Os` on x86-64 (`make size`); Thumb-2 and RISC-V builds are typically smaller. Disabling floats or optional features shrinks it further.
- **RAM:** the arena. A stock C module needs about 100 KB with the default 64 KiB guest memory. With `ECCLES_WASM_MEM_LIMIT_BYTES` and a small guest stack it fits in far less. See [Memory Sizing](Memory-Sizing).

Chips with under 64 KB of RAM can run small modules; chips with 256 KB or more (ESP32, RP2040, STM32F4+, nRF52840) run stock modules comfortably.

# Bring-Up Checklist

A procedure that gets Eccles WASM running on any microcontroller, in small steps. Every step has one clear pass signal. If a step fails, fix only that step before moving on. Most chips are running by step 4.

## Step 0: prove it on your PC first

```bash
git clone https://github.com/igwe-starking/eccles-wasm && cd eccles-wasm
make examples && build/example_host examples/blink.wasm
```

If this fails, the problem is your PC toolchain, not your chip.

## Step 1: prove your chip's toolchain with no wasm at all

Build and flash a plain "blink and print" program using your normal SDK. If you cannot see output from the chip, nothing below can be diagnosed. Get a serial console working first.

## Step 2: add the library and compile

Add `eccles_wasm.c` to the build and `src/` to the include path ([Install](Install)). Build. Pass signal: it compiles and links.

| Problem | Fix |
|---|---|
| `eccles_wasm.h: No such file` | include path is missing `src/` |
| undefined `sqrt` / `sqrtf` | link the math library (`-lm`), or define `ECCLES_WASM_NO_FLOAT` |
| the wrong backend is picked | force it: `-DECCLES_WASM_PLATFORM=ECCLES_WASM_PLAT_ESP_IDF` (or `_ARDUINO`, `_PICO`, `_STM32_HAL`, `_ZEPHYR`, `_NONE`) |
| `.c` file compiled as C++ | name it `.c`; in Arduino it is already handled |
| overflow of `.bss` or `region 'RAM' overflowed` | the arena is bigger than your RAM: set `-DECCLES_WASM_ARENA_SIZE=...` ([Memory Sizing](Memory-Sizing)) |

## Step 3: run the smoke test

Make the test module and its C array on your PC:

```bash
clang --target=wasm32 -O2 -nostdlib -ffreestanding -Wl,--no-entry -Wl,--export-all \
  -Wl,-z,stack-size=4096 -Wl,--initial-memory=65536 -Isdk/c -o hello.wasm examples/wiki/guest/hello.c
python3 tools/wasm2c.py hello.wasm hello_wasm.h hello_wasm
```

Add `hello_wasm.h` and this file to your project, and call `eccles_bringup()` once from `main()`:

```c
/* bringup.c - the smoke test to run first on any new chip. Call eccles_bringup() from your main().
 * It needs only hello_wasm.h (make it with: python3 tools/wasm2c.py hello.wasm hello_wasm.h hello_wasm).
 * It prints one line per stage; the first stage that does not say OK is where to look (see the Bring-Up Checklist wiki page).
 * On a chip without printf, define BRINGUP_PRINT(...) before this file, for example to Serial.printf or ESP_LOGI. */
#include "eccles_wasm.h"
#include "hello_wasm.h"

#ifndef BRINGUP_PRINT
#include <stdio.h>
#define BRINGUP_PRINT(...) printf(__VA_ARGS__)
#endif

int eccles_bringup(void) {
    uint64_t args[2], res[1];
    eccles_wasm_stats_t s;

    BRINGUP_PRINT("eccles-wasm %s\n", ECCLES_WASM_VERSION_STRING);

    /* 1. load (checks: arena size, runtime compiled in, module accepted) */
    if (eccles_wasm_load_buffer(hello_wasm, hello_wasm_len) != ECCLES_WASM_SUCCESSFUL) {
        BRINGUP_PRINT("stage 1 load:    FAIL  %s, info %u (see Error Reference)\n",
                      eccles_wasm_error_name(eccles_wasm_last_error()), (unsigned)eccles_wasm_last_error_info());
        return 1;
    }
    BRINGUP_PRINT("stage 1 load:    OK\n");

    /* 2. compute (checks: the interpreter itself) */
    args[0] = eccles_wasm_from_i32(20);
    args[1] = eccles_wasm_from_i32(22);
    if (eccles_wasm_call("add", args, 2, res, 1) != ECCLES_WASM_SUCCESSFUL || eccles_wasm_to_i32(res[0]) != 42) {
        BRINGUP_PRINT("stage 2 compute: FAIL  %s\n", eccles_wasm_error_name(eccles_wasm_last_error()));
        return 2;
    }
    BRINGUP_PRINT("stage 2 compute: OK    add(20, 22) = 42\n");

    /* 3. memory report (checks: the arena and the guest memory exist; eccles_wasm_get_stats() also has arena_used) */
    s = eccles_wasm_get_stats();
    BRINGUP_PRINT("stage 3 memory:  OK    arena %u bytes, guest memory %u bytes\n",
                  (unsigned)s.arena_size, (unsigned)s.memory_bytes);

    /* 4. privileges (checks: deny-by-default works) */
    eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_NONE);
    eccles_wasm_run("hello");                           /* hello() wants the console and the clock */
    if (eccles_wasm_denied_count() == 0) {
        BRINGUP_PRINT("stage 4 denied:  FAIL  the module was not refused\n");
        return 4;
    }
    BRINGUP_PRINT("stage 4 denied:  OK    refused calls: %u (last: %s)\n", (unsigned)eccles_wasm_denied_count(), eccles_wasm_last_denied());

    /* 5. console from the guest (checks: the log backend) */
    eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_SAFE);
    BRINGUP_PRINT("stage 5 console: the next line comes from inside the module:\n");
    if (eccles_wasm_run("hello") != ECCLES_WASM_SUCCESSFUL) {
        BRINGUP_PRINT("stage 5 console: FAIL  %s\n", eccles_wasm_error_name(eccles_wasm_last_error()));
        return 5;
    }
    BRINGUP_PRINT("bring-up complete: PASS\n");
    return 0;
}

#ifdef BRINGUP_MAIN
int main(void) { return eccles_bringup(); }
#endif
```
*(file: `examples/wiki/host/bringup.c`)*

Expected output (on a chip the time and sizes differ):

```text
eccles-wasm 2.0.0
stage 1 load:    OK
stage 2 compute: OK    add(20, 22) = 42
stage 3 memory:  OK    arena 1046784 bytes, guest memory 65536 bytes
stage 4 denied:  OK    refused calls: 2 (last: log)
stage 5 console: the next line comes from inside the module:
hello from wasm, running for 0 ms
bring-up complete: PASS
```

Where it stops tells you what to fix:

| Stops at | Meaning | Go to |
|---|---|---|
| stage 1 `no memory` | arena too small (the number printed is the bytes needed) | [Memory Sizing](Memory-Sizing) |
| stage 1 `module exceeds a configured limit` | module bigger than a configured limit | [Troubleshooting](Troubleshooting) |
| stage 1 `malformed module` | the array is corrupt or truncated | regenerate it with `tools/wasm2c.py` |
| stage 2 fails | a build option mismatch between your code and `eccles_wasm.c` | [Troubleshooting](Troubleshooting#crashes-and-resets) |
| stage 4 does not refuse | `ECCLES_WASM_DEFAULT_PRIVILEGE` was changed | [Configuration](Configuration-Reference) |
| stage 5 prints nothing | no console backend: Arduino needs `eccles_wasm_use_serial(Serial)`, STM32 and others need a HAL override for `log` | your platform page |
| the chip resets or hangs | stack too small or a watchdog | [Troubleshooting](Troubleshooting#crashes-and-resets) |

Pass signal: `bring-up complete: PASS`.

## Step 4: touch real hardware

Compile the LED module, embed it, grant pins, run it:

```c
eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_PIN_ALL | ECCLES_WASM_ALLOW_SAFE);
eccles_wasm_load_buffer(led_wasm, led_wasm_len);
uint64_t a[1] = { eccles_wasm_from_i32(5) };
eccles_wasm_call("blink", a, 1, NULL, 0);        // blinks pin 2 five times
```

The module is `examples/wiki/guest/led.c`; it uses pin 2. Change `#define LED 2` to your board's LED pin number (see [Platforms Overview](Platforms-Overview) for numbering). Pass signal: the LED blinks and the console says `blink finished with status 0 (ok)`.

If it prints status `3 (denied)`, you skipped the grant. If `2 (unsupported)`, the backend lacks that function on your chip ([capability table](Platforms-Overview)). If `1 (failed)`, the pin number is invalid for the chip.

## Step 5: size it for production

Run `eccles_wasm_get_stats()` after loading your real module. Set `ECCLES_WASM_ARENA_SIZE` a little above `arena_used`, and `ECCLES_WASM_MEM_LIMIT_BYTES` to what the guest really uses ([Memory Sizing](Memory-Sizing)). Set a fuel limit: `eccles_wasm_set_fuel(...)` ([Safety](Safety-Fuel-and-Traps)).

## Step 6: load from storage or the network (optional)

- Arduino, ESP-IDF: `eccles_wasm_load("/littlefs/app.wasm")`, see [Loading Modules](Loading-Modules).
- Your own storage: [Custom Filesystems](Custom-Filesystems).
- OTA or a socket: `eccles_wasm_load_stream`.

## Step 7: add threads (optional)

Only if the guest spawns threads. Add `ECCLES_WASM_ATOMICS=1`, `ECCLES_WASM_THREADS=1`, a spawner and a hardware lock: [Threads and the Spawner](Threads-and-Spawner).

## When it still does not work

1. Enable `-DECCLES_WASM_DEBUG` and define `ECCLES_WASM_LOG_LINE(msg)` to print: load failures are then logged.
2. Print `eccles_wasm_error_name(eccles_wasm_last_error())`, `eccles_wasm_last_error_info()` and `eccles_wasm_last_error_str()` after every failed call.
3. Find your message in [Troubleshooting](Troubleshooting).
4. Open an issue with the chip, SDK version, your config, and that output.

# Platform: Arduino

Works with the Arduino IDE and PlatformIO on any Arduino core that has enough RAM: ESP32 (all variants), Arduino Nano 33 BLE and other nRF52 boards, RP2040 boards, Uno R4, SAMD51, Teensy and similar. Tested on ESP32 and Arduino Nano 33 BLE.

Not for AVR (Uno R3, Nano, Mega): they have 2 to 8 KB of RAM, and the library refuses to compile there unless you set an arena explicitly.

## 1. Install

See [Install](Install#arduino-ide). In the IDE, include with `#include <eccles_wasm.h>`.

## 2. Get a module onto the board

Pick one:

| Way | How | Needs |
|---|---|---|
| Embedded in the sketch | `python3 tools/wasm2c.py app.wasm app_wasm.h app_wasm`, then `eccles_wasm_load_buffer(app_wasm, app_wasm_len)` | nothing else; best for first tests |
| LittleFS / SPIFFS / SD file | `File f = LittleFS.open("/app.wasm"); eccles_wasm_load(f);` | a mounted file system |
| Anything with a `Stream` | `eccles_wasm_load(stream)` | SD, `FFat`, `WiFiClient`, a Serial port |

## 3. A complete sketch (ESP32, LittleFS)

```cpp
// Arduino-ESP32: load /app.wasm from LittleFS, drive GPIO + I2C + Serial from the guest.
#include <LittleFS.h>
#include <Wire.h>
#include <eccles_wasm.h>

void setup() {
  Serial.begin(115200);
  LittleFS.begin(true);
  eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_PIN_ALL | ECCLES_WASM_ALLOW_SAFE | ECCLES_WASM_PERM_I2C);   // v2: grant what the module may use
  eccles_wasm_use_serial(Serial);          // guest log() / printf output -> Serial
  eccles_wasm_use_wire(Wire);              // guest i2c_* -> Wire (bus 0)

  File f = LittleFS.open("/app.wasm");     // streamed through ECCLES_WASM_CHUNK_SIZE bytes at a time
  if (eccles_wasm_load(f) != ECCLES_WASM_SUCCESSFUL) {
    Serial.printf("load failed: %s\n", eccles_wasm_error_name(eccles_wasm_last_error()));
    return;
  }
  f.close();
  eccles_wasm_run("setup");
}

void loop() { eccles_wasm_run("loop"); }
```
*(file: `examples/arduino_esp32_littlefs/arduino_esp32_littlefs.ino`)*

Line by line:

1. `set_hal_privilege(...)` grants the module pins, time, console and I2C. Without it every hardware call returns 3.
2. `use_serial(Serial)` sends the guest's `ew_printf` output to the Serial monitor.
3. `use_wire(Wire)` connects the guest's I2C calls to `Wire`. Similarly `eccles_wasm_use_spi(SPI)` and `eccles_wasm_use_uart(Serial1, 1)`.
4. `eccles_wasm_load(f)` streams the file; close it after loading.
5. `loop()` runs the guest's `loop` export on every Arduino loop.

The guest side:

```c
/* clang --target=wasm32 -O2 -nostdlib -ffreestanding -Wl,--no-entry -Wl,-z,stack-size=4096 \
 *       -Wl,--initial-memory=65536 -I../../sdk/c -o blink.wasm blink.c                          */
#define EW_ARDUINO_COMPAT              /* optional: pinMode/digitalWrite/delay/millis names */
#include "eccles_wasm_runtime.h"

#define LED 2

EW_EXPORT("setup") void setup(void) {
    pinMode(LED, OUTPUT);
    ew_printf("blink up at %u ms (pin %d)\n", (unsigned)millis(), LED);
    if (ew_dac(25, 100) == EW_UNSUPPORTED) ew_println("no DAC on this chip - fine");
}

EW_EXPORT("loop") void loop(void) {
    digitalWrite(LED, HIGH); delay(500);
    digitalWrite(LED, LOW);  delay(500);
}
```
*(file: `examples/guest/blink.c`)*

## 4. Embedded module sketch (any board)

```cpp
#include <eccles_wasm.h>
#include "app_wasm.h"                      // made by tools/wasm2c.py

void setup() {
  Serial.begin(115200);
  eccles_wasm_use_serial(Serial);
  eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_PIN_ALL | ECCLES_WASM_ALLOW_SAFE);
  if (eccles_wasm_load_buffer(app_wasm, app_wasm_len) != ECCLES_WASM_SUCCESSFUL) {
    Serial.printf("load failed: %s\n", eccles_wasm_error_name(eccles_wasm_last_error()));
    return;
  }
  eccles_wasm_run("setup");
}

void loop() { eccles_wasm_run("loop"); }
```

On boards whose `Serial` lacks `printf` (most non-ESP boards) use `Serial.println(eccles_wasm_error_name(eccles_wasm_last_error()));`.

## 5. Board notes

| Board | Memory | Settings |
|---|---|---|
| ESP32, S2, S3, C3 | heap arena, 96 KB default | nothing needed; set `ECCLES_WASM_ARENA_SIZE` for production |
| Arduino Nano 33 BLE (nRF52840, 256 KB) | static arena | `-DECCLES_WASM_ARENA_SIZE=(96ul*1024ul)` |
| RP2040 / Pico W (Arduino-Pico or mbed core) | static arena | same as above |
| Uno R4, SAMD51 (32 KB RAM or less) | tight | `-DECCLES_WASM_ARENA_SIZE=(20ul*1024ul) -DECCLES_WASM_MEM_LIMIT_BYTES=(4ul*1024ul)`, small guests only |

Pins are Arduino pin numbers. Features: GPIO, analog (PWM duty), ADC and time are built in; ESP32 adds random, reset, deep sleep. I2C, SPI, UART, console come from the `use_*` helpers. Interrupt counters and `pwm` (frequency) are not in the Arduino backend; the guest receives 2 (unsupported). For ESP32 with those features use ESP-IDF, or add them with a [HAL override](Platform-Other-MCUs#hal-override).

## 6. Settings with PlatformIO

```ini
build_flags =
    -DECCLES_WASM_ARENA_SIZE=98304ul
    -DECCLES_WASM_MEM_LIMIT_BYTES=16384ul
```

With the Arduino IDE, edit `libraries/eccles-wasm/src/eccles_wasm_config.h` (copy it from `config/` first).

## 7. Common problems

| Symptom | Fix |
|---|---|
| module does nothing, no errors | no privilege granted: add `eccles_wasm_set_hal_privilege(...)` |
| no output from `ew_printf` | add `eccles_wasm_use_serial(Serial)` and grant `ECCLES_WASM_PERM_LOG` |
| `load failed: out of arena memory` | raise `ECCLES_WASM_ARENA_SIZE`, or cap guest memory with `ECCLES_WASM_MEM_LIMIT_BYTES` |
| I2C reads fail | call `Wire.begin()` first, then `eccles_wasm_use_wire(Wire)`, grant `ECCLES_WASM_PERM_I2C` |
| ESP32 watchdog reset during a long guest loop | set a fuel limit, see [Safety](Safety-Fuel-and-Traps) |

More: [Troubleshooting](Troubleshooting).

# Platform: ESP-IDF

The most complete backend: GPIO, PWM (LEDC), ADC, UART, I2C, SPI, pin interrupt counters, watchdog, deep sleep, random and console. Validated on a real ESP32 (see [Validation](Validation)): ESP-IDF 5.1.2, PlatformIO `espressif32@6.5.0`.

## 1. Add the library

Copy the folder to `components/eccles-wasm/`, or use a git dependency ([Install](Install#esp-idf-component)).

## 2. The smallest project

```c
/* ESP-IDF: run a wasm module from flash, or from a file on SPIFFS/LittleFS/FATFS/SD. */
#include "eccles_wasm.h"
#include "blink_wasm.h"                     /* examples/blink_wasm.h: the module as a C array */
#include "esp_log.h"

void app_main(void) {
    /* v2: modules get NO hardware until you grant it. Blink needs pins + sleep + console. */
    eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_PIN_ALL | ECCLES_WASM_ALLOW_SAFE);

    /* A) from a C array in flash (nothing is copied; translated code lives in the arena) */
    eccles_wasm_status_t st = eccles_wasm_load_buffer(blink_wasm, sizeof blink_wasm);

    /* B) from a file - mount your filesystem first (esp_vfs_spiffs_register / esp_vfs_fat_sdmmc_mount ...),
          then the path is the VFS path; the file is streamed in ECCLES_WASM_CHUNK_SIZE pieces:
          st = eccles_wasm_load("/spiffs/app.wasm");                                                    */
    if (st != ECCLES_WASM_SUCCESSFUL) {
        ESP_LOGE("wasm", "load failed: %s (info %u)", eccles_wasm_error_name(eccles_wasm_last_error()),
                 (unsigned)eccles_wasm_last_error_info());
        return;
    }
    eccles_wasm_set_fuel(2000000);          /* a runaway guest traps instead of tripping the task watchdog */
    eccles_wasm_run("setup");
    for (;;) eccles_wasm_run("loop");       /* pins: ESP-IDF GPIO numbers; guest LED pin 2 */
}
```
*(file: `examples/esp_idf/main/main.c`)*

```cmake
# main/CMakeLists.txt
idf_component_register(SRCS "main.c" INCLUDE_DIRS "." REQUIRES eccles-wasm)
```

Get `blink_wasm.h` from `examples/blink_wasm.h`, or make your own with `tools/wasm2c.py`.

## 3. Load from a file

Mount a file system with the standard ESP-IDF calls, then the path is the VFS path:

```c
esp_vfs_spiffs_conf_t conf = { .base_path = "/spiffs", .partition_label = NULL, .max_files = 4, .format_if_mount_failed = true };
esp_vfs_spiffs_register(&conf);
eccles_wasm_load("/spiffs/app.wasm");
```

LittleFS, FAT and SD cards work the same way, since ESP-IDF exposes them through the C `fopen` interface. See [Loading Modules](Loading-Modules).

## 4. Settings

`sdkconfig.defaults` that the validation firmware used:

```
CONFIG_ESP_MAIN_TASK_STACK_SIZE=16384
CONFIG_ESP_TASK_WDT_CHECK_IDLE_TASK_CPU0=n
CONFIG_ESP_TASK_WDT_CHECK_IDLE_TASK_CPU1=n
CONFIG_ESP_INT_WDT=y
CONFIG_ESP_CONSOLE_UART_BAUDRATE=115200
CONFIG_COMPILER_OPTIMIZATION_PERF=y
```
*(file: `validation/01-conformance-suite/firmware/sdkconfig.defaults`)*

- `CONFIG_ESP_MAIN_TASK_STACK_SIZE=16384`: the interpreter and the load path use C stack on the calling task. The validation firmware ran with 16 KB; start there and reduce once you have measured.
- The arena is allocated from the heap by default (96 KB). Set `ECCLES_WASM_ARENA_SIZE` to what you need. It needs one contiguous block, so allocate early, before WiFi and Bluetooth fragment the heap.

`eccles_wasm_config.h` of the validation firmware (atomics, threads, a hardware lock for several instances):

```c
/* Picked up automatically by eccles_wasm.h. Settings the test suite needs. */
#pragma once
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "freertos/semphr.h"

#define ECCLES_WASM_ATOMICS      1      /* threads-proposal atomics + shared memory */
#define ECCLES_WASM_THREADS      1      /* wasi-threads: thread-spawn + sibling instances */

/* pins and buses are shared between instances: one recursive mutex (created in app_main) */
extern SemaphoreHandle_t g_hw_mx;
#define ECCLES_WASM_HW_LOCK()    xSemaphoreTakeRecursive(g_hw_mx, portMAX_DELAY)
#define ECCLES_WASM_HW_UNLOCK()  xSemaphoreGiveRecursive(g_hw_mx)

/* long-running guest code must let the idle task (and its watchdog) run: every 2^20 back-branches/calls */
#define ECCLES_WASM_FUEL            1
#define ECCLES_WASM_YIELD_INTERVAL  1048576
#define ECCLES_WASM_YIELD()         vTaskDelay(1)
```
*(file: `validation/01-conformance-suite/firmware/src/eccles_wasm_config.h`)*

Create the mutex once in `app_main()`: `g_hw_mx = xSemaphoreCreateRecursiveMutex();`

## 5. Speed settings

For the fastest loop: `-DECCLES_WASM_FUEL=0` and `-DECCLES_WASM_EXEC_IRAM=1`, with `CONFIG_COMPILER_OPTIMIZATION_PERF=y`. See [Speed Tuning](Speed-Tuning). The interpreter loop is large, and IRAM is limited and shared with all other IRAM code, so check the link map when you enable it.

## 6. Pins, ADC, buses

- Pin = GPIO number.
- ADC: ADC1 and ADC2 channels by GPIO; with WiFi on, ADC2 pins do not work (hardware limitation).
- I2C bus numbers follow `I2C_NUM_*`, UART ports follow `UART_NUM_*`.
- SPI bus 0 = SPI2 (HSPI), bus 1 = SPI3 (VSPI); transfers longer than 4000 bytes are split into several transactions automatically.
- `pwm`: 8 channels share one LEDC timer, so changing the frequency of one PWM pin changes all of them.
- Deep sleep restarts the chip, so the module starts again from `setup`.

## 7. Threads

Use `xTaskCreate` in the spawner: [Threads and the Spawner](Threads-and-Spawner#freertos-esp-idf-stm32cube-freertos-pico-freertos).

## 8. Common problems

| Symptom | Fix |
|---|---|
| `Task watchdog got triggered` | a guest loop runs too long without yielding: set `eccles_wasm_set_fuel(n)`, or make the guest call `ew_yield()` or `ew_sleep()` |
| `Stack overflow in task main` | raise `CONFIG_ESP_MAIN_TASK_STACK_SIZE` |
| `load failed: out of arena memory` | the heap has no contiguous block of `ECCLES_WASM_ARENA_SIZE`; lower it or allocate before WiFi starts; set `MEM_LIMIT_BYTES` |
| warnings stop the build | in your component's `CMakeLists.txt` add `target_compile_options(${COMPONENT_LIB} PRIVATE -Wno-error)` (the validation firmware does) |

More: [Troubleshooting](Troubleshooting).

# Platform: Raspberry Pi Pico

Backend for the Pico SDK: RP2040 (Pico, Pico W) and RP2350. Supports GPIO, PWM, ADC, UART, I2C, SPI, pin interrupt counters, watchdog, random and console. The `deep_sleep` import returns unsupported.

## 1. CMake

```cmake
cmake_minimum_required(VERSION 3.13)
include($ENV{PICO_SDK_PATH}/external/pico_sdk_import.cmake)
project(app C CXX ASM)
pico_sdk_init()

add_executable(app main.c eccles-wasm/src/eccles_wasm.c)
target_include_directories(app PRIVATE eccles-wasm/src .)
target_link_libraries(app pico_stdlib hardware_gpio hardware_adc hardware_pwm
                      hardware_i2c hardware_spi hardware_uart hardware_watchdog pico_rand)
pico_enable_stdio_usb(app 1)
pico_add_extra_outputs(app)
```

## 2. A complete program

```c
/* Raspberry Pi Pico SDK. CMake: target_link_libraries(app pico_stdlib hardware_gpio hardware_adc
 * hardware_pwm hardware_i2c hardware_spi hardware_uart hardware_watchdog pico_rand)  +  add eccles_wasm.c.
 * For a file instead of an array, add a FatFs port (e.g. no-OS-FatFS-SD-SDIO-SPI-RPi-Pico): ff.h on the
 * include path switches eccles_wasm_load("0:/app.wasm") on automatically. */
#include "pico/stdlib.h"
#include "eccles_wasm.h"
#include "blink_wasm.h"

int main(void) {
    stdio_init_all();
    eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_PIN_ALL | ECCLES_WASM_ALLOW_SAFE);     /* v2: grant what the module may use */
    if (eccles_wasm_load_buffer(blink_wasm, sizeof blink_wasm) != ECCLES_WASM_SUCCESSFUL) return 1;
    eccles_wasm_run("setup");               /* guest LED = GP2 (use 25 for the on-board LED: edit the guest) */
    for (;;) eccles_wasm_run("loop");
}
```
*(file: `examples/pico/main.c`)*

Make `blink_wasm.h` from `examples/blink_wasm.h` or `tools/wasm2c.py`. The example blink guest uses GP2; to use the on-board LED edit the guest's pin to `25` (Pico) or the correct GPIO for your board (Pico W uses the radio chip for its LED: use an external LED on a GP pin).

## 3. Numbering

- Pin = GP number (0 to 29 on RP2040).
- ADC: GP26 to GP29 only.
- UART 0, 1; I2C 0, 1; SPI 0, 1.
- `pwm` and `analog` are on slices: two pins on the same slice share a frequency.

## 4. Memory

The arena is a static array by default, 96 KB. RP2040 has 264 KB of RAM, so a stock module fits. To squeeze more room set `-DECCLES_WASM_ARENA_SIZE=...` and `-DECCLES_WASM_MEM_LIMIT_BYTES=...` with `target_compile_definitions(app PRIVATE ...)`.

## 5. Loading from files

Add a FatFs SD library for the Pico: when `ff.h` is on the include path, `eccles_wasm_load("0:/app.wasm")` works automatically. For other storage see [Custom Filesystems](Custom-Filesystems).

## 6. Speed

`ECCLES_WASM_EXEC_IRAM=1` puts the loop in `.time_critical` (RAM). Combined with `ECCLES_WASM_FUEL=0` that is the fastest configuration. See [Speed Tuning](Speed-Tuning).

## 7. Threads

The Pico has two cores. Use FreeRTOS SMP or the Pico multicore API in your spawner: [Threads and the Spawner](Threads-and-Spawner).

## 8. Common problems

| Symptom | Fix |
|---|---|
| no output on the USB serial | `pico_enable_stdio_usb(app 1)` and wait for the host to open the port; grant `ECCLES_WASM_PERM_LOG` |
| `adc` returns failed | pin is not 26 to 29 |
| link error for `pwm_*`, `adc_*` | add `hardware_pwm`, `hardware_adc` to `target_link_libraries` |
| `ECCLES_WASM_ARENA_SIZE` too big: `region RAM overflowed` | lower the arena |

More: [Troubleshooting](Troubleshooting).

# Platform: STM32

Backend for the STM32 HAL (CubeMX / STM32CubeIDE projects). GPIO, time and reset work out of the box. UART, I2C and SPI work after you list your CubeMX handles in the config file. `analog`, `adc`, `pwm`, `random`, `log` and interrupt counters are not in the STM32 backend: the guest receives 2 (unsupported) unless you add them with a [HAL override](Platform-Other-MCUs#hal-override).

## 1. Add the files

Copy `eccles_wasm.c` and `eccles_wasm.h` into your project (`Core/Src`, `Core/Inc`) and add the include path. Create `eccles_wasm_config.h` next to `eccles_wasm.h`:

```c
#include "main.h"
extern UART_HandleTypeDef huart2;
extern I2C_HandleTypeDef  hi2c1;
extern SPI_HandleTypeDef  hspi1;

#define ECCLES_WASM_TOTAL_RAM_SIZE      (128ul * 1024ul)     /* your chip's RAM; the arena is derived from it */
#define ECCLES_WASM_MEM_LIMIT_BYTES     (16ul * 1024ul)      /* guest memory actually backed */
#define ECCLES_WASM_STM32_UART_HANDLES  { &huart2 }
#define ECCLES_WASM_STM32_I2C_HANDLES   { &hi2c1 }
#define ECCLES_WASM_STM32_SPI_HANDLES   { &hspi1 }
```

The position in each list is the port/bus number the guest uses: `{ &huart2 }` makes UART 0 = USART2. If your HAL header is not `main.h`, define `ECCLES_WASM_STM32_HAL_HEADER "your_hal.h"`.

## 2. The program

```c
/* STM32 (CubeMX project). Add src/eccles_wasm.c to the build, and next to eccles_wasm.h create
 * eccles_wasm_config.h with (adapt to your handles):
 *
 *   #include "main.h"
 *   extern UART_HandleTypeDef huart2;  extern I2C_HandleTypeDef hi2c1;  extern SPI_HandleTypeDef hspi1;
 *   #define ECCLES_WASM_TOTAL_RAM_SIZE      (128ul * 1024ul)
 *   #define ECCLES_WASM_MEM_LIMIT_BYTES     (16ul * 1024ul)           // guest memory actually backed
 *   #define ECCLES_WASM_STM32_UART_HANDLES  { &huart2 }
 *   #define ECCLES_WASM_STM32_I2C_HANDLES   { &hi2c1 }
 *   #define ECCLES_WASM_STM32_SPI_HANDLES   { &hspi1 }
 *
 * Pins are port*16+bit: PA5 = 5, PB0 = 16, PC13 = 45. With FatFs (ff.h on the include path) you can
 * eccles_wasm_load("0:/app.wasm") straight from the SD card. */
#include "eccles_wasm.h"
#include "blink_wasm.h"

void app_main_loop(void) {                  /* call from main() after MX_*_Init() */
    eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_PIN_ALL | ECCLES_WASM_ALLOW_SAFE);     /* v2: grant what the module may use */
    if (eccles_wasm_load_buffer(blink_wasm, sizeof blink_wasm) != ECCLES_WASM_SUCCESSFUL) Error_Handler();
    eccles_wasm_run("setup");
    for (;;) eccles_wasm_run("loop");
}
```
*(file: `examples/stm32_cubemx/main_snippet.c`)*

Call `app_main_loop()` from `main()` after the `MX_*_Init()` calls and before the `while (1)` loop.

## 3. Numbering

Pin = `port * 16 + bit`: PA0 = 0, PA5 = 5, PB0 = 16, PC13 = 45. The backend enables the GPIO port clock for you.

## 4. Memory

The arena is a static array. Unless you set `ECCLES_WASM_ARENA_SIZE` yourself, it is derived from `ECCLES_WASM_TOTAL_RAM_SIZE` (half the RAM, or 24 KB plus a quarter, whichever is smaller). A default 64 KiB guest memory plus the module's code does not fit in 48 KB, so on chips with under 128 KB set `ECCLES_WASM_MEM_LIMIT_BYTES` and link guests with a small memory (see [Memory Sizing](Memory-Sizing)).

Ready settings:

| Chip RAM | Config |
|---|---|
| 20 to 32 KB (F0, L0, G0) | `ARENA_SIZE=(16ul*1024ul)`, `MEM_LIMIT_BYTES=(2ul*1024ul)`, `VALUE_STACK_SLOTS=128`, `CHUNK_SIZE=64`; guest linked with 2 KB stack and 1 page |
| 64 to 128 KB (F1, F3, L4, G4) | `ARENA_SIZE=(40ul*1024ul)`, `MEM_LIMIT_BYTES=(8ul*1024ul)` |
| 192 KB and more (F4, F7, H7, U5) | defaults, with `TOTAL_RAM_SIZE` |

These are starting points: measure with `eccles_wasm_get_stats()`.

## 5. Files from an SD card (FatFs)

With the FatFs middleware (`ff.h` on the include path) `eccles_wasm_load("0:/app.wasm")` works. For anything else use [Custom Filesystems](Custom-Filesystems).

## 6. Speed

`ECCLES_WASM_EXEC_IRAM=1` puts the loop in `.RamFunc` (your linker script must place `.RamFunc` in RAM; CubeMX scripts do). On Cortex-M7 parts with cache the flash is usually already fast: measure before enabling.

## 7. Threads

STM32Cube with FreeRTOS (CMSIS-RTOS2): use `xTaskCreate` in the spawner: [Threads and the Spawner](Threads-and-Spawner).

## 8. Common problems

| Symptom | Fix |
|---|---|
| `uart_begin` returns unsupported | the handle list macro is missing, or the HAL module (`HAL_UART_MODULE_ENABLED`) is off in `stm32xxxx_hal_conf.h` |
| hard fault at start | stack too small (raise `_Min_Stack_Size` and heap in the linker script), or the arena is larger than RAM |
| `.bss` overflow | arena too big for the chip |
| guest toggles the wrong pin | wrong numbering: use `port*16+bit` |

More: [Troubleshooting](Troubleshooting).

# Platform: Zephyr and nRF Connect SDK

Backend for Zephyr (nRF52, nRF53, nRF91, STM32 under Zephyr, and every other Zephyr board). GPIO, time, random, reset and console work out of the box. UART, I2C, SPI, ADC, PWM are not in this backend: the guest receives 2 (unsupported) unless you add them with a [HAL override](Platform-Other-MCUs#hal-override).

## 1. Project files

`prj.conf`:

```
CONFIG_REBOOT=y
CONFIG_ENTROPY_GENERATOR=y
CONFIG_MAIN_STACK_SIZE=4096
# only if you load from a file:
# CONFIG_FILE_SYSTEM=y
```

`CMakeLists.txt`:

```cmake
cmake_minimum_required(VERSION 3.20.0)
find_package(Zephyr REQUIRED HINTS $ENV{ZEPHYR_BASE})
project(app)
target_sources(app PRIVATE src/main.c ../eccles-wasm/src/eccles_wasm.c)
target_include_directories(app PRIVATE ../eccles-wasm/src ../eccles-wasm/examples)
```

## 2. The program

```c
/* Zephyr / nRF Connect SDK. pin = port*32 + bit (gpio0 = 0..31, gpio1 = 32..63).
 * prj.conf: CONFIG_REBOOT=y  CONFIG_ENTROPY_GENERATOR=y  (and CONFIG_FILE_SYSTEM=y + a mounted fs for load(path))
 * CMakeLists: target_sources(app PRIVATE src/main.c ../../src/eccles_wasm.c)  target_include_directories(app PRIVATE ../../src ../) */
#include <zephyr/kernel.h>
#include "eccles_wasm.h"
#include "blink_wasm.h"

int main(void) {
    eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_PIN_ALL | ECCLES_WASM_ALLOW_SAFE);     /* v2: grant what the module may use */
    if (eccles_wasm_load_buffer(blink_wasm, sizeof blink_wasm) != ECCLES_WASM_SUCCESSFUL) return 1;
    eccles_wasm_run("setup");
    for (;;) eccles_wasm_run("loop");
}
```
*(file: `examples/zephyr/src/main.c`)*

## 3. Numbering

Pin = `port * 32 + bit`, over the devicetree labels `gpio0` to `gpio3`: P0.13 = 13, P1.08 = 40.

## 4. Memory

The arena is a static array, 48 KB by default. nRF52840 (256 KB) can take 96 KB: set the macro with `zephyr_compile_definitions(ECCLES_WASM_ARENA_SIZE=98304ul)`. nRF52832 (64 KB) needs `ECCLES_WASM_ARENA_SIZE` near 24 KB plus `ECCLES_WASM_MEM_LIMIT_BYTES`.

## 5. Console

`log` goes to the Zephyr console. Enable `CONFIG_PRINTK=y` (default) and a console backend (`CONFIG_UART_CONSOLE=y` or RTT).

## 6. Loading from files

With `CONFIG_FILE_SYSTEM=y` and a mounted file system, `eccles_wasm_load("/lfs/app.wasm")` uses Zephyr's fs API. For another source see [Custom Filesystems](Custom-Filesystems).

## 7. Threads

Create a Zephyr thread in the spawner with `k_thread_create` and a statically allocated stack pool: [Threads and the Spawner](Threads-and-Spawner#zephyr).

## 8. Common problems

| Symptom | Fix |
|---|---|
| `gpio` returns failed | the port is not enabled in the devicetree (`gpio1` on a board without it), or the pin number is out of range |
| reset import unsupported | `CONFIG_REBOOT=y` is missing |
| main thread stack overflow | `CONFIG_MAIN_STACK_SIZE` is too small |

More: [Troubleshooting](Troubleshooting).

# Platform: Other MCUs and HAL Override

Any chip with a C99 compiler and enough RAM can run Eccles WASM. The interpreter is portable C; only the hardware functions are chip-specific, and you write only the ones your modules use.

## Requirements

- A 32-bit (or 64-bit) CPU and a C99 compiler. 16-bit and 8-bit parts (AVR, MSP430, PIC, 8051) are refused at compile time unless you set `ECCLES_WASM_ARENA_SIZE` yourself, because a module needs tens of KB.
- RAM for the arena (about 12 KB for a tiny module, about 100 KB for a stock module, see [Memory Sizing](Memory-Sizing)).
- About 50 KB of flash.

## Step by step

1. Add `eccles_wasm.c` to your build, and `src/` to the include path.
2. Select no backend: `-DECCLES_WASM_PLATFORM=ECCLES_WASM_PLAT_NONE`. (If your compiler defines nothing recognisable, `PLAT_NONE` is what you get anyway.)
3. Set the arena: `-DECCLES_WASM_ARENA_SIZE=(32ul*1024ul)`. It is a static array unless you define `ECCLES_WASM_USE_HEAP=1`.
4. Load the module from flash with `eccles_wasm_load_buffer()`. Without a backend there is no file loading (`eccles_wasm_load(path)` returns `no filesystem backend`) until you call `eccles_wasm_set_fs`, see [Custom Filesystems](Custom-Filesystems).
5. Write the hardware functions you need (next section).

## HAL override

`eccles_wasm_hal_override(&ops)` replaces backend functions at run time. Fill only the fields you implement. The others keep their previous value, which on `PLAT_NONE` is "unsupported". A guest calling an unsupported function simply gets status 2.

The fields, one per guest import: `gpio_mode`, `gpio_write`, `gpio_read`, `analog`, `pwm`, `adc`, `dac`, `millis`, `micros`, `sleep_ms`, `sleep_us`, `yield`, `deep_sleep`, `reset`, `random`, `wdt_feed`, `log`, `irq_attach`, `irq_count`, `irq_clear`, `irq_detach`, `uart_begin`, `uart_write`, `uart_read`, `uart_end`, `i2c_begin`, `i2c_write`, `i2c_read`, `i2c_write_read`, `spi_begin`, `spi_transfer`, `spi_end`. Signatures are in [Host API Reference](Host-API-Reference#hal-override).

Return values: `ECCLES_WASM_SUCCESSFUL` (0) when done, `ECCLES_WASM_FAILED` (1) for a bad argument or a hardware error, `ECCLES_WASM_UNSUPPORTED` (2) when the chip cannot do it.

A complete, runnable example (the "chip" is a few variables so it runs on a PC; replace the bodies with register accesses):

```c
/* custom_hal.c - run Eccles WASM on a chip that has no built-in backend.
 * You write only the hardware functions your guests use; every other function stays UNSUPPORTED (2).
 * Here the "chip" is a few variables so the example runs on a PC; on your chip, replace the bodies with register writes. */
#include "eccles_wasm.h"
#include <stdio.h>

static uint32_t g_pins;                 /* stand-in for your GPIO output register */
static uint32_t g_ms;                   /* stand-in for your millisecond tick */

static eccles_wasm_status_t my_mode(uint32_t pin, uint32_t mode) {
    if (pin > 31) return ECCLES_WASM_FAILED;                    /* FAILED: the pin does not exist on this chip */
    (void)mode;                                                 /* set the pin's direction register here */
    return ECCLES_WASM_SUCCESSFUL;
}
static eccles_wasm_status_t my_write(uint32_t pin, uint32_t level) {
    if (pin > 31) return ECCLES_WASM_FAILED;
    if (level) g_pins |= 1u << pin; else g_pins &= ~(1u << pin);
    return ECCLES_WASM_SUCCESSFUL;
}
static eccles_wasm_status_t my_read(uint32_t pin, uint32_t *level) {
    if (pin > 31) return ECCLES_WASM_FAILED;
    *level = (g_pins >> pin) & 1u;
    return ECCLES_WASM_SUCCESSFUL;
}
static eccles_wasm_status_t my_millis(uint32_t *ms) { *ms = g_ms; return ECCLES_WASM_SUCCESSFUL; }
static eccles_wasm_status_t my_sleep(uint32_t ms) { g_ms += ms; return ECCLES_WASM_SUCCESSFUL; }   /* a real chip waits here */
static eccles_wasm_status_t my_log(const uint8_t *buf, uint32_t len) {
    fwrite(buf, 1, len, stdout);                                /* a real chip writes to its UART here */
    return ECCLES_WASM_SUCCESSFUL;
}

int main(int argc, char **argv) {
    const char *path = argc > 1 ? argv[1] : "build/wiki/led.wasm";
    uint64_t a[1] = { 3 }, r[1];

    eccles_wasm_hal_t hal = {0};                                /* every field you leave NULL stays as it was (UNSUPPORTED here) */
    hal.gpio_mode = my_mode;
    hal.gpio_write = my_write;
    hal.gpio_read = my_read;
    hal.millis = my_millis;
    hal.sleep_ms = my_sleep;
    hal.log = my_log;
    eccles_wasm_hal_override(&hal);

    eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_PIN_ALL | ECCLES_WASM_ALLOW_SAFE);
    if (eccles_wasm_load(path) != ECCLES_WASM_SUCCESSFUL) return 1;
    eccles_wasm_call("blink", a, 1, r, 1);
    printf("pin register = 0x%08X, uptime = %u ms\n", (unsigned)g_pins, (unsigned)g_ms);

    eccles_wasm_call("led_on", NULL, 0, r, 1);
    printf("led_on() = %d, pin register = 0x%08X\n", (int)r[0], (unsigned)g_pins);
    return 0;
}
```
*(file: `examples/wiki/host/custom_hal.c`)*

Output:

```text
blink finished with status 0 (ok)
pin register = 0x00000000, uptime = 600 ms
led_on() = 0, pin register = 0x00000004
```

The minimum for most guests is five functions: `gpio_mode`, `gpio_write`, `millis`, `sleep_ms` and `log`.

## Which functions does my guest need?

Compile the guest, then look at its imports: `wasm-objdump -x app.wasm | grep Import` (WABT), or run the module and print `eccles_wasm_last_denied()`. The [Guest Import Reference](Guest-Import-Reference) lists which function each import uses.

## Adding a feature on top of a built-in backend

The same function works on a supported platform. For example, give the STM32 backend an ADC:

```c
static eccles_wasm_status_t my_adc(uint32_t pin, uint32_t *value) {
    HAL_ADC_Start(&hadc1);
    HAL_ADC_PollForConversion(&hadc1, 10);
    *value = HAL_ADC_GetValue(&hadc1);
    return ECCLES_WASM_SUCCESSFUL;
}
...
eccles_wasm_hal_t hal = {0};
hal.adc = my_adc;
eccles_wasm_hal_override(&hal);
```

`eccles_wasm_hal_reset()` goes back to the built-in backend.

## Chips with several RAM regions or external RAM

Place the arena where you want with `eccles_wasm_init_with(mem, size)`, or per instance with `eccles_wasm_vm_create(mem, size)`. Call it before the first load.

## Testing your override on a PC first

Because `eccles_wasm_hal_override` is portable, test the same guest on the [desktop simulator](Platform-Desktop-Simulator), then switch to your chip.

# Platform: Desktop Simulator

On Linux, macOS and Windows (any hosted C compiler) the runtime uses a simulated chip: pins, ADC, PWM, UART, I2C, SPI and interrupts live in memory. You can develop and test guests without any hardware, in CI, and under sanitizers.

## Build

```bash
gcc -std=c99 -O2 -DECCLES_WASM_HOST_VIRTUAL_TIME -Isrc your_main.c src/eccles_wasm.c -o app -lm
```

`ECCLES_WASM_HOST_VIRTUAL_TIME` makes `sleep` instant: the clock jumps forward instead of waiting. Leave it out for real time. For tests that start threads add `-pthread -DECCLES_WASM_THREADSAFE`.

## Inspect and drive the simulated chip

| Function | Purpose |
|---|---|
| `eccles_wasm_sim_reset()` | clear every pin, buffer and counter |
| `eccles_wasm_sim_pin_mode(pin)`, `eccles_wasm_sim_pin_level(pin)` | what the guest set |
| `eccles_wasm_sim_set_input(pin, level)` | what `read` returns |
| `eccles_wasm_sim_set_adc(pin, value)` | what `adc` returns |
| `eccles_wasm_sim_pwm_duty(pin)`, `eccles_wasm_sim_pwm_freq(pin)` | PWM state |
| `eccles_wasm_sim_irq_fire(pin, edge)` | trigger an interrupt edge |
| `eccles_wasm_sim_uart_feed(port, data, len)`, `eccles_wasm_sim_uart_take(port, out, max)` | UART receive buffer / transmitted bytes |
| `eccles_wasm_sim_i2c_set_response(bus, data, len)` | what the "sensor" answers |
| `eccles_wasm_sim_i2c_last_write(bus, out, max)`, `eccles_wasm_sim_i2c_last_addr(bus)` | what the guest sent |
| `eccles_wasm_sim_reset_requested()` | did the guest call `reset` |

Example: [03_sensors.c](Cookbook#read-sensors-adc-and-i2c) uses ADC and I2C on the simulator.

## The `wsrun` command-line tool

```bash
make
build/wsrun hello.wasm add 14 16        # arguments are hexadecimal: 0x14 = 20, 0x16 = 22
```

Output: `OK 2a 0 0 0 0 0 0 0` - the first number is the result in hex (0x2a = 42), the rest are unused result slots. A trap prints `TRAP <reason>`; a failed load prints `LOADFAIL <reason>`. `wsrun --stdin` reads one `export arg arg ...` per line. It grants all privileges, since it is a developer tool.

## Using the simulator as your CI test bench

A guest that works on the simulator with the same privileges will behave the same on the chip, except for timing and the features the chip's backend lacks (see the [capability table](Platforms-Overview)).

## Threads on the desktop

When the build defines `ECCLES_WASM_THREADSAFE` on a Linux or macOS host and you have not defined your own `ECCLES_WASM_HW_LOCK`, the runtime provides a pthread mutex. `eccles_wasm_host_lock()` and `eccles_wasm_host_unlock()` are the two functions behind it, and the runtime calls them around every short simulated hardware operation. You do not call them yourself. To use a different lock, define `ECCLES_WASM_HW_LOCK()` and `ECCLES_WASM_HW_UNLOCK()` in your config (see [Configuration Reference](Configuration-Reference)).

# Writing Guests

A guest is the program that runs inside Eccles WASM. You write it in C, C++ or Rust, compile it on your PC to a `.wasm` file, and give that file to the chip. One `.wasm` runs unchanged on every supported chip.

## C

Install `clang` and `wasm-ld` ([Install](Install#the-guest-toolchain-on-your-pc-not-the-chip)).

```c
/* hello.c - the smallest useful guest: one function that computes, one that prints. */
#include "eccles_wasm_runtime.h"

EW_EXPORT("add") int add(int a, int b) { return a + b; }

EW_EXPORT("fib") int fib(int n) {
    int a = 0, b = 1;
    while (n-- > 0) { int t = a + b; a = b; b = t; }
    return a;
}

EW_EXPORT("hello") void hello(void) {
    ew_printf("hello from wasm, running for %u ms\n", (unsigned)ew_millis());
}
```
*(file: `examples/wiki/guest/hello.c`)*

Compile:

```bash
clang --target=wasm32 -O2 -nostdlib -ffreestanding \
  -Wl,--no-entry -Wl,--export-all \
  -Wl,-z,stack-size=4096 -Wl,--initial-memory=65536 \
  -Isdk/c -o app.wasm app.c
```

What each flag does:

| Flag | Why |
|---|---|
| `--target=wasm32` | produce WebAssembly |
| `-O2` (or `-Oz` for smallest) | optimise |
| `-nostdlib -ffreestanding` | no C library: use `ew_printf` and static buffers |
| `-Wl,--no-entry` | a library, no `main` |
| `-Wl,--export-all` | export every non-static function (or mark them with `EW_EXPORT("name")` and drop this flag) |
| `-Wl,-z,stack-size=4096` | the guest's C stack: 4 KB. Smaller guests can use 1024 to 2048. Default would be 64 KB, which does not fit small chips |
| `-Wl,--initial-memory=65536` | one WebAssembly page (64 KiB): the smallest allowed |
| `-Isdk/c` | the SDK header `eccles_wasm_runtime.h` |

## The shape of a guest

- **Exports** are what the host can call: `EW_EXPORT("name") int fn(...)`.
- **Imports** are what the host provides: everything in `eccles_wasm_runtime.h` (`ew_enable`, `ew_sleep`, ...) and your own functions ([Host Functions](Host-Functions)).
- The names `setup` and `loop` are a convention, not magic. The host calls whatever you export: `eccles_wasm_run("setup")`.
- Prefer one entry point instead? Export `main`, put your setup at the top and a `for (;;)` loop with `ew_sleep` inside, and call `eccles_wasm_run("main")` once. See [Two ways to structure a module](Concepts#two-ways-to-structure-a-module).
- A `start` function, or global constructors, run during load (set `ECCLES_WASM_AUTORUN_START 0` to disable).
- Arguments and results are `int`, `long long`, `float`, `double`. Pointers are 32-bit offsets into the guest's own memory.

## Arduino-style names

```c
#define EW_ARDUINO_COMPAT
#include "eccles_wasm_runtime.h"

#define LED 2
EW_EXPORT("setup") void setup(void) { pinMode(LED, OUTPUT); }
EW_EXPORT("loop")  void loop(void)  { digitalWrite(LED, HIGH); delay(500); digitalWrite(LED, LOW); delay(500); }
```

Provides `pinMode`, `digitalWrite`, `digitalRead`, `analogWrite`, `analogRead`, `delay`, `delayMicroseconds`, `millis`, `micros`, plus `HIGH`, `LOW`, `INPUT`, `OUTPUT`, `INPUT_PULLUP`.

## Handle every status

Each `ew_*` call returns `EW_OK` (0), `EW_FAILED` (1), `EW_UNSUPPORTED` (2) or `EW_DENIED` (3). Check it when it matters:

```c
int st = ew_adc(34, &value);
if (st == EW_UNSUPPORTED) { /* this chip has no ADC: use a default */ }
if (st == EW_DENIED)      { /* the host did not grant PERM_ADC */ }
```

`ew_status_name(st)` gives a string. The examples [led.c](Cookbook#blink-an-led-and-see-the-status) and [sensor.c](Cookbook#read-sensors-adc-and-i2c) show the pattern.

## Printing

`ew_printf(fmt, ...)` supports `%d %i %u %x %X %c %s %p %%`, width, zero-padding and `l`/`ll`. It is small, runs without libc and needs `PERM_LOG` on the host. Also `ew_print(str)` and `ew_println(str)`. Floats are not printed by `ew_printf`: print them as integers (`(int)(x * 100)`).

## C++

```cpp
#include "eccles_wasm_runtime.h"

static ew::Pin led(2);
static ew::I2c i2c(0);

EW_EXPORT("setup") extern "C" void setup() {
    led.output();
    if (i2c.begin(21, 22) == EW_OK) {
        uint8_t reg = 0x00, id = 0;
        if (i2c.write_read(0x68, &reg, 1, &id, 1) == EW_OK) ew_printf("chip id 0x%02X\n", id);
    }
}
EW_EXPORT("loop") extern "C" void loop() { led.toggle(); ew::sleep(500); }
```

```bash
clang++ --target=wasm32 -O2 -nostdlib -fno-exceptions -fno-rtti -ffreestanding \
  -Wl,--no-entry -Wl,-z,stack-size=4096 -Wl,--initial-memory=65536 -Isdk/c -o app.wasm app.cpp
```

`ew::Pin`, `ew::I2c`, `ew::Spi` are thin wrappers with no exceptions, RTTI or heap. No `new`/`delete`, no STL, no `<iostream>`.

## Rust

```bash
rustup target add wasm32-unknown-unknown
cd sdk/rust/examples/blink && cargo build --release --target wasm32-unknown-unknown
# -> target/wasm32-unknown-unknown/release/blink.wasm
```

```rust
//! cd sdk/rust/examples/blink && cargo build --release --target wasm32-unknown-unknown
//! -> target/wasm32-unknown-unknown/release/blink.wasm  (copy to the chip's filesystem)
#![no_std]
use eccles_wasm_runtime::{millis, println, sleep_ms, Edge, Error, Pin};

const LED: Pin = Pin(2);
const BUTTON: Pin = Pin(0);

#[no_mangle]
pub extern "C" fn setup() {
    println!("blink (Rust) up at {} ms", millis());
    let _ = LED.output();
    // Unsupported is a normal answer on some chips - handle it instead of crashing.
    match BUTTON.input_pullup().and_then(|_| BUTTON.irq_attach(Edge::Falling)) {
        Ok(()) => println!("button interrupts on"),
        Err(Error::Unsupported) => println!("this chip has no pin-interrupt support"),
        Err(Error::Denied) => println!("the host has not granted pin interrupts to this module"),
        Err(Error::Failed) => println!("button setup failed"),
    }
}

#[no_mangle]
pub extern "C" fn tick() {
    let _ = LED.toggle();
    if let Ok(n) = BUTTON.irq_count() {
        if n > 0 { println!("button pressed {} time(s)", n); let _ = BUTTON.irq_clear(); }
    }
    sleep_ms(250);
}
```
*(file: `sdk/rust/examples/blink/src/lib.rs`)*

The crate `eccles-wasm-runtime` (`sdk/rust`) gives `Pin`, `sleep_ms`, `millis`, `println!`, an `Error` enum (`Failed`, `Unsupported`, `Denied`), and with the `embedded-hal` feature the embedded-hal 1.0 traits so existing driver crates run inside the module. Use `opt-level = "z"`, `lto`, `panic = "abort"` as in the example's `Cargo.toml`.

## Using the standard C library (wasi-sdk)

With [wasi-sdk](https://github.com/WebAssembly/wasi-sdk) you can use `printf`, `malloc`, `memcpy`, and so on. The built-in WASI covers `fd_write` (needs `PERM_LOG`), `proc_exit`, `clock_time_get` (needs `PERM_TIME`), `random_get` (needs `PERM_RANDOM`), `args_*`, `environ_*` and `sched_yield`. Files and sockets are not available. Stdlib code makes modules bigger and uses more memory; prefer `-nostdlib` and the SDK on small chips.

## Making modules small

| Technique | Effect |
|---|---|
| `-Oz` | smaller code |
| `-Wl,--gc-sections` (on by default) and `static` helpers | drops unused code |
| `-Wl,-z,stack-size=1024` | the biggest single saving of RAM |
| `-Wl,--initial-memory=65536` | one page. The host can back less with `MEM_LIMIT_BYTES` |
| avoid `ew_printf` in tiny modules | it pulls in a formatter (about 2 KB) |
| `wasm-opt -Oz` (binaryen) | usually another 10 to 20 percent |
| `wasm-strip` (wabt) | removes the name section |

## Putting a module on the chip

| Way | Command |
|---|---|
| C array in firmware | `python3 tools/wasm2c.py app.wasm app_wasm.h app_wasm` |
| File on the chip's file system | copy `app.wasm` to LittleFS/SD/SPIFFS, then `eccles_wasm_load("/path")` |
| Over the air | download into `eccles_wasm_load_stream` |

All covered in [Loading Modules](Loading-Modules).

## Check what a module needs

- Its imports tell which hardware it uses: `wasm-objdump -x app.wasm | grep -A40 Import` (WABT).
- Its size: `ls -l app.wasm`.
- After loading, `eccles_wasm_get_stats()` reports the arena it takes on the chip.

# Guest Import Reference

Every function a guest can call, what it needs, and what it does. The C names are in `sdk/c/eccles_wasm_runtime.h`; the module import name (second column) is what shows up in the `.wasm`. All imports live in the module `env`.

Every function returns a status: `0` OK, `1` FAILED, `2` UNSUPPORTED, `3` DENIED. Functions that produce a value write it through a pointer. **DENIED is checked first**: a refused call never touches the hardware.

## GPIO

| C function | Import | Needs | Notes |
|---|---|---|---|
| `ew_pin_mode(pin, mode)` | `mode` | `GPIO_CONFIG` | modes: `EW_INPUT` 0, `EW_OUTPUT` 1, `EW_INPUT_PULLUP` 2, `EW_INPUT_PULLDOWN` 3, `EW_OPEN_DRAIN` 4 |
| `ew_enable(pin)` | `enable` | `GPIO_WRITE` | drive high |
| `ew_disable(pin)` | `disable` | `GPIO_WRITE` | drive low |
| `ew_toggle(pin)` | `toggle` | `GPIO_WRITE` | |
| `ew_write(pin, level)` | `write` | `GPIO_WRITE` | level 0 or 1 |
| `ew_read(pin, &level)` | `read` | `GPIO_READ` | level written to `*level`; helper `ew_digital_read(pin)` |

## Analog

| C function | Import | Needs | Notes |
|---|---|---|---|
| `ew_analog(pin, value)` | `analog` | `ANALOG_OUT` | PWM duty 0..255 (`ECCLES_WASM_ANALOG_MAX`) |
| `ew_pwm(pin, freq_hz, duty16)` | `pwm` | `ANALOG_OUT` | frequency and 16-bit duty (0..65535) |
| `ew_adc(pin, &value)` | `adc` | `ADC` | raw reading; helper `ew_analog_read(pin)` |
| `ew_dac(pin, value)` | `dac` | `ANALOG_OUT` | no built-in backend has a DAC: returns 2 unless you add one |

## Time

| C function | Import | Needs | Notes |
|---|---|---|---|
| `ew_sleep(ms)` | `sleep` | `TIME` | blocks this instance (other tasks run) |
| `ew_sleep_us(us)` | `sleep_us` | `TIME` | |

| `ew_micros_(&v)` / `ew_micros()` | `micros` | `TIME` | wraps at 2^32 us (71 minutes) |
| `ew_yield()` | `yield` | `TIME` | let other tasks run |

| C function | Import | Needs | Notes |
|---|---|---|---|

| C function | Import | Needs |
|---|---|---|

| `ew_irq_clear(pin)` | `irq_clear` | `IRQ` |
| `ew_irq_detach(pin)` | `irq_detach` | `IRQ` |

# Loading Modules

Four ways to get a `.wasm` into the runtime. The module is never held in RAM whole: file and stream loads read 256 bytes at a time (`ECCLES_WASM_CHUNK_SIZE`), and buffer loads read straight from where the array lives (flash).

| Way | Call | Use it when |
|---|---|---|
| Array in firmware | `eccles_wasm_load_buffer(ptr, len)` | first tests, fixed firmware, chips with no file system |
| File | `eccles_wasm_load("/path/app.wasm")` | the module changes without reflashing |
| Your own storage | `eccles_wasm_set_fs(open, read, close)` then `eccles_wasm_load(path)` | any file system or flash layout the library does not know |
| Any byte source | `eccles_wasm_load_stream(read_fn, ctx)` | OTA downloads, UART, sockets, SPI flash, encrypted storage |

Every load returns `ECCLES_WASM_SUCCESSFUL` or `ECCLES_WASM_FAILED`. After a failure nothing is loaded. Read the reason with `eccles_wasm_last_error()` ([Error Reference](Error-Reference)).

What a load does, in order: reads the sections, checks the module is well formed, links every import (built-in hardware imports and the ones you registered), translates the code into the arena, creates memory, runs the data segments, and runs the module's start function. Loading another module first discards the previous one.

## Array in firmware

```bash
python3 tools/wasm2c.py app.wasm app_wasm.h app_wasm
```

```c
/* 09_buffer_embed.c - the module lives inside the firmware image (flash), nothing is copied to RAM.
 * Make the array with:   python3 tools/wasm2c.py app.wasm app_wasm.h app_wasm   (or xxd -i) */
#include "eccles_wasm.h"
#include <stdio.h>
#include "hello_wasm.h"                           /* generated: const unsigned char hello_wasm[]; const unsigned int hello_wasm_len; */

int main(void) {
    uint64_t a[2] = { 5, 6 }, r[1];
    if (eccles_wasm_load_buffer(hello_wasm, hello_wasm_len) != ECCLES_WASM_SUCCESSFUL) return 1;
    eccles_wasm_call("add", a, 2, r, 1);
    printf("embedded module: add(5, 6) = %d\n", (int)eccles_wasm_to_i32(r[0]));
    return 0;
}
```
*(file: `examples/wiki/host/09_buffer_embed.c`)*

Output:

```text
embedded module: add(5, 6) = 11
```

The array is `const`, so on ARM, ESP32 and RP2040 it stays in flash. On AVR-style chips with a separate flash space it would need `PROGMEM`, but those chips are too small for the runtime anyway.

## File from the platform's file system

| Platform | What `eccles_wasm_load("path")` uses |
|---|---|
| Desktop, ESP-IDF, mbed | the C library `fopen` (ESP-IDF: any mounted VFS: SPIFFS, LittleFS, FAT, SD) |
| Anything with FatFs (`ff.h` on the include path) | FatFs: `"0:/app.wasm"` |
| Zephyr with `CONFIG_FILE_SYSTEM=y` | Zephyr's fs API |
| LittleFS | define `ECCLES_WASM_FS=ECCLES_WASM_FS_LITTLEFS` and `ECCLES_WASM_LFS_PTR=(&my_lfs)` |
| Arduino (C++) | `File f = LittleFS.open("/app.wasm"); eccles_wasm_load(f);` (works for SD, SPIFFS, FFat, `WiFiClient`: anything with `Stream`) |
| nothing | `eccles_wasm_load(path)` returns status 2 (`UNSUPPORTED`) with the error `no filesystem backend`: use `set_fs` |

Force a choice with `-DECCLES_WASM_FS=ECCLES_WASM_FS_STDIO` (also `_FATFS`, `_LITTLEFS`, `_ZEPHYR`, `_NONE`).

ESP-IDF example:

```c
esp_vfs_spiffs_conf_t conf = { .base_path = "/spiffs", .max_files = 4, .format_if_mount_failed = true };
esp_vfs_spiffs_register(&conf);
if (eccles_wasm_load("/spiffs/app.wasm") != ECCLES_WASM_SUCCESSFUL) { /* handle */ }
```

If your storage is anything else, read [Custom Filesystems](Custom-Filesystems): it is three small functions.

## Stream: any source of bytes

`eccles_wasm_load_stream(read, ctx)` calls your function until it returns 0. The function may hand over any number of bytes up to `max`:

```c
/* 08_stream.c - load a module from a byte source that is NOT a file: a UART, a network socket, an OTA download, SPI flash.
 * The read callback hands over whatever bytes it has; the loader asks again until it returns 0. */
#include "eccles_wasm.h"
#include <stdio.h>
#include <stdlib.h>

typedef struct { uint8_t *data; size_t len, pos; } source_t;

static int read_cb(void *ctx, uint8_t *buf, size_t max) {
    source_t *s = (source_t *)ctx;
    size_t n = s->len - s->pos;
    if (n > 37) n = 37;                       /* a trickling source: 37 bytes per call. any size works */
    if (n > max) n = max;
    for (size_t i = 0; i < n; i++) buf[i] = s->data[s->pos + i];
    s->pos += n;
    return (int)n;                            /* 0 = no more data, negative = error */
}

int main(int argc, char **argv) {
    const char *path = argc > 1 ? argv[1] : "build/wiki/hello.wasm";
    FILE *fp = fopen(path, "rb"); if (!fp) { puts("cannot open demo file"); return 1; }
    source_t s = {0}; fseek(fp, 0, SEEK_END); s.len = (size_t)ftell(fp); fseek(fp, 0, SEEK_SET);
    s.data = (uint8_t *)malloc(s.len);
    if (fread(s.data, 1, s.len, fp) != s.len) return 1;
    fclose(fp);

    if (eccles_wasm_load_stream(read_cb, &s) == ECCLES_WASM_SUCCESSFUL) {
        uint64_t a[2] = { 1, 2 }, r[1];
        eccles_wasm_call("add", a, 2, r, 1);
        printf("streamed the module in 37-byte pieces; add(1, 2) = %d\n", (int)eccles_wasm_to_i32(r[0]));
    }

    /* a truncated download is detected, not executed */
    s.pos = 0; s.len = s.len / 2;
    if (eccles_wasm_load_stream(read_cb, &s) != ECCLES_WASM_SUCCESSFUL)
        printf("half a module -> %s\n", eccles_wasm_error_name(eccles_wasm_last_error()));
    return 0;
}
```
*(file: `examples/wiki/host/08_stream.c`)*

Output:

```text
streamed the module in 37-byte pieces; add(1, 2) = 3
half a module -> malformed module
```

The read callback contract:

| Return | Meaning |
|---|---|
| `> 0` | that many bytes were written to `buf` (at most `max`) |
| `0` | end of data |
| `< 0` | read error: the load fails with `I/O error` |

OTA over WiFi or cellular: the callback reads from the HTTP client, with no copy of the module in RAM. Verify a hash or signature of the download before calling load if the module is untrusted: the runtime only checks structure, it does not authenticate.

## Unload and reload

```c
eccles_wasm_unload();                          // frees the module's arena space
eccles_wasm_load_buffer(new_wasm, new_len);    // or just load: it replaces the old one
```

Host functions registered earlier stay registered across loads. Privileges, fuel and the spawner stay too.

## The start function

A module's `start` function (and C global constructors) runs at the end of the load. A trap there makes the load fail. Disable it with `-DECCLES_WASM_AUTORUN_START=0`. If the module calls WASI `proc_exit(code)`, ask with `eccles_wasm_exited(&code)`.

## Check what you loaded

```c
eccles_wasm_stats_t s = eccles_wasm_get_stats();
// s.arena_size, s.arena_used, s.memory_bytes, s.memory_pages, s.code_bytes, s.functions, s.imports, s.exports, s.loaded
if (eccles_wasm_has_export("setup")) eccles_wasm_run("setup");
```

# Custom Filesystems: `eccles_wasm_set_fs`

Use `eccles_wasm_set_fs` when the module sits somewhere the library cannot read by itself: a file system it does not know, a raw SPI flash partition, an SD card with your own driver, an encrypted store, a network file. You give it three functions, then `eccles_wasm_load("any-name")` works.

## The whole feature in one picture

```c
eccles_wasm_set_fs(my_open, my_read, my_close);       // once, at start-up
eccles_wasm_load("/disk/app.wasm");                   // the string is passed to my_open unchanged
```

## The three functions

| Function | Signature | Contract |
|---|---|---|
| open | `void *open(const char *path)` | return a handle for the file, or `NULL` when it cannot be opened (the load then fails with `I/O error`) |
| read | `int read(void *file, uint8_t *buf, size_t max)` | write up to `max` bytes into `buf` and return how many; return `0` at end of file; return a negative number on error |
| close | `void close(void *file)` | free the handle. Optional: pass `NULL` if there is nothing to close |

The handle is yours: any pointer (a `FILE *`, a struct, a flash offset record). The runtime passes it back to `read` and `close` and never looks inside. `close` is always called after a successful `open`, also when the load fails.

`set_fs(NULL, NULL, NULL)`, or passing `NULL` for `open` or `read`, switches back to the platform's own file system.

## Example you can run

A "disk" in RAM, loaded through the three functions:

```c
/* 06_set_fs.c - load .wasm files from ANY storage by giving the runtime three small functions.
 * This demo's "storage" is a table of files in RAM; swap the three functions for FatFs / LittleFS / SPI flash / a network
 * client and nothing else changes (see 06b_fs_snippets.c). */
#include "eccles_wasm.h"
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct { const char *name; uint8_t *data; size_t len; } ramfile_t;
static ramfile_t g_files[4]; static int g_nfiles;

typedef struct { const ramfile_t *f; size_t pos; } handle_t;          /* what open() hands back and read()/close() receive */

static void *my_open(const char *path) {                          /* return NULL when the file does not exist */
    for (int i = 0; i < g_nfiles; i++)
        if (strcmp(g_files[i].name, path) == 0) {
            handle_t *h = (handle_t *)malloc(sizeof *h);
            if (!h) return NULL;
            h->f = &g_files[i]; h->pos = 0;
            return h;
        }
    return NULL;
}
static int my_read(void *file, uint8_t *buf, size_t max) {          /* bytes read, 0 = end of file, negative = error */
    handle_t *h = (handle_t *)file;
    size_t n = h->f->len - h->pos;
    if (n > max) n = max;
    memcpy(buf, h->f->data + h->pos, n);
    h->pos += n;
    return (int)n;
}
static void my_close(void *file) { free(file); }

static void add_file(const char *name, const char *real_path) {     /* fill the RAM "disk" from a real file (demo only) */
    FILE *fp = fopen(real_path, "rb"); if (!fp) return;
    fseek(fp, 0, SEEK_END); long n = ftell(fp); fseek(fp, 0, SEEK_SET);
    g_files[g_nfiles].name = name; g_files[g_nfiles].data = (uint8_t *)malloc((size_t)n); g_files[g_nfiles].len = (size_t)n;
    if (fread(g_files[g_nfiles].data, 1, (size_t)n, fp) != (size_t)n) { fclose(fp); return; }
    fclose(fp); g_nfiles++;
}

int main(int argc, char **argv) {
    const char *dir = argc > 1 ? argv[1] : "build/wiki";
    char path[256]; uint64_t a[2] = { 40, 2 }, r[1];

    snprintf(path, sizeof path, "%s/hello.wasm", dir);
    add_file("/disk/app.wasm", path);

    eccles_wasm_set_fs(my_open, my_read, my_close);                 /* the whole feature is this one line */

    if (eccles_wasm_load("/disk/app.wasm") == ECCLES_WASM_SUCCESSFUL) {
        eccles_wasm_call("add", a, 2, r, 1);
        printf("loaded /disk/app.wasm through my own filesystem: add(40, 2) = %d\n", (int)eccles_wasm_to_i32(r[0]));
    }
    if (eccles_wasm_load("/disk/missing.wasm") != ECCLES_WASM_SUCCESSFUL)
        printf("missing file -> %s\n", eccles_wasm_error_name(eccles_wasm_last_error()));

    eccles_wasm_set_fs(NULL, NULL, NULL);                           /* back to the platform's own file system */
    return 0;
}
```
*(file: `examples/wiki/host/06_set_fs.c`)*

Output:

```text
loaded /disk/app.wasm through my own filesystem: add(40, 2) = 42
missing file -> I/O error
```

## Recipes

These are compile-checked against stub headers by `make wiki-examples`.

```c
/* 06b_fs_snippets.c - set_fs for the common embedded file systems. This file is compile-checked against stub headers
 * (make wiki-examples); on a real board the headers come from FatFs / LittleFS / your SDK. */
#include "eccles_wasm.h"
#include <stdlib.h>

#if defined(USE_FATFS)
#include "ff.h"
static void *fat_open(const char *path) {
    FIL *f = (FIL *)malloc(sizeof *f);
    if (!f) return NULL;
    if (f_open(f, path, FA_READ) != FR_OK) { free(f); return NULL; }
    return f;
}
static int fat_read(void *file, uint8_t *buf, size_t max) {
    UINT got = 0;
    return f_read((FIL *)file, buf, (UINT)max, &got) == FR_OK ? (int)got : -1;
}
static void fat_close(void *file) { f_close((FIL *)file); free(file); }
void use_fatfs(void) { eccles_wasm_set_fs(fat_open, fat_read, fat_close); }
#endif

#if defined(USE_LITTLEFS)
#include "lfs.h"
extern lfs_t my_lfs;                                       /* your mounted file system */
static void *lfs_open_cb(const char *path) {
    lfs_file_t *f = (lfs_file_t *)malloc(sizeof *f);
    if (!f) return NULL;
    if (lfs_file_open(&my_lfs, f, path, LFS_O_RDONLY) < 0) { free(f); return NULL; }
    return f;
}
static int lfs_read_cb(void *file, uint8_t *buf, size_t max) { return (int)lfs_file_read(&my_lfs, (lfs_file_t *)file, buf, (lfs_size_t)max); }
static void lfs_close_cb(void *file) { lfs_file_close(&my_lfs, (lfs_file_t *)file); free(file); }
void use_littlefs(void) { eccles_wasm_set_fs(lfs_open_cb, lfs_read_cb, lfs_close_cb); }
#endif

#if defined(USE_STDIO)                                    /* ESP-IDF VFS (SPIFFS, LittleFS, FAT, SD) and any libc */
#include <stdio.h>
static void *std_open(const char *path) { return fopen(path, "rb"); }
static int std_read(void *file, uint8_t *buf, size_t max) { return (int)fread(buf, 1, max, (FILE *)file); }
static void std_close(void *file) { fclose((FILE *)file); }
void use_stdio(void) { eccles_wasm_set_fs(std_open, std_read, std_close); }
#endif
```
*(file: `examples/wiki/host/06b_fs_snippets.c`)*

Compile one at a time with `-DUSE_FATFS`, `-DUSE_LITTLEFS` or `-DUSE_STDIO`.

### A raw flash partition (no file system)

A module stored at a fixed address, with its length in the first 4 bytes:

```c
typedef struct { uint32_t addr, left; } flash_file_t;

static void *flash_open(const char *path) {
    (void)path;
    flash_file_t *f = malloc(sizeof *f);
    if (!f) return NULL;
    flash_read(PARTITION_ADDR, (uint8_t *)&f->left, 4);      /* your flash driver */
    f->addr = PARTITION_ADDR + 4;
    return f;
}
static int flash_read_cb(void *file, uint8_t *buf, size_t max) {
    flash_file_t *f = file;
    uint32_t n = f->left < max ? f->left : (uint32_t)max;
    if (n) { flash_read(f->addr, buf, n); f->addr += n; f->left -= n; }
    return (int)n;
}
static void flash_close(void *file) { free(file); }
...
eccles_wasm_set_fs(flash_open, flash_read_cb, flash_close);
eccles_wasm_load("app");        // the name is ignored by this open()
```

### Several modules by name

`open` receives the path, so one `set_fs` can serve many modules:

```c
static void *my_open(const char *path) {
    if (strcmp(path, "motor") == 0)  return make_handle(MOTOR_ADDR, MOTOR_LEN);
    if (strcmp(path, "sensor") == 0) return make_handle(SENSOR_ADDR, SENSOR_LEN);
    return NULL;
}
...
eccles_wasm_load("motor");
```

### Decrypting while loading

Wrap the read: read ciphertext from storage into `buf`, decrypt in place, return the count. The module never exists in RAM in clear text, apart from the 256-byte chunk.

## Rules

- `set_fs` is process-wide: it applies to every instance. Do not change it while another task is loading.
- Heap-allocate the handle (or use a pool) in `open`, do not return a pointer to a shared static if two loads can overlap.
- The built-in FatFs and LittleFS backends use one static file object, so two loads at the same time are not possible with them. With `set_fs` and a per-call handle they are.
- Do not call back into the runtime from inside these functions.
- `read` may return fewer bytes than asked. Returning 0 early looks like a truncated module and fails with `malformed module`.

## Troubleshooting

| Symptom | Cause |
|---|---|
| `I/O error` | `open` returned `NULL`: wrong path string, file system not mounted, or `read` returned a negative number |
| `malformed module` with `info` equal to a small offset | `read` returned 0 too early, or you return ASCII instead of binary (open the file in binary mode: `"rb"`) |
| `no filesystem backend` (status 2) | `set_fs` was not called, or one of `open`/`read` is `NULL`: both are required |
| works once, fails the second time | `close` does not release the handle, or `open` reuses a handle that is already at end of file |

# Host Functions: your own imports

A host function is a C function in your firmware that the guest can call. Use it for anything the built-in hardware imports do not cover: a display, a motor driver, a network call, a sensor library, a database, a callback into your application.

## Three steps

1. Write the function.
2. Register it with a name and a type signature, **before loading**.
3. Declare it in the guest with the same name and types.

```c
/* 04_host_import.c - give the guest a function of your own. */
#include "eccles_wasm.h"
#include <stdio.h>

/* slots[0..nparams) are the arguments, the result goes back into slots[0] */
static eccles_wasm_status_t host_scale(eccles_wasm_vm_t *vm, uint64_t *slots) {
    (void)vm;
    int32_t value  = eccles_wasm_to_i32(slots[0]);
    int32_t factor = eccles_wasm_to_i32(slots[1]);
    slots[0] = eccles_wasm_from_i32(value * factor);
    return ECCLES_WASM_SUCCESSFUL;                  /* anything else traps the guest */
}

int main(int argc, char **argv) {
    const char *path = argc > 1 ? argv[1] : "build/wiki/scaled.wasm";
    uint64_t a[1] = { 14 }, r[1];

    eccles_wasm_register("host_scale", host_scale, "i(ii)");    /* BEFORE load: "returns i32, takes i32 i32" */

    if (eccles_wasm_load(path) != ECCLES_WASM_SUCCESSFUL) {
        printf("load failed: %s \"%s\"\n", eccles_wasm_error_name(eccles_wasm_last_error()), eccles_wasm_last_error_str());
        return 1;
    }
    eccles_wasm_call("run", a, 1, r, 1);
    printf("run(14) = %d   (14 * 3 + 1)\n", (int)eccles_wasm_to_i32(r[0]));

    /* what happens when you forget to register it? */
    eccles_wasm_unregister_all();
    if (eccles_wasm_load(path) != ECCLES_WASM_SUCCESSFUL)
        printf("without register: %s \"%s\"\n", eccles_wasm_error_name(eccles_wasm_last_error()), eccles_wasm_last_error_str());
    return 0;
}
```
*(file: `examples/wiki/host/04_host_import.c`)*

The guest:

```c
/* scaled.c - calls a function that YOUR firmware provides ("host_scale") */
#include "eccles_wasm_runtime.h"

EW_IMPORT("host_scale") int host_scale(int value, int factor);

EW_EXPORT("run") int run(int x) { return host_scale(x, 3) + 1; }
```
*(file: `examples/wiki/guest/scaled.c`)*

Output:

```text
run(14) = 43   (14 * 3 + 1)
without register: unresolved import "host_scale"
```

## The function shape

```c
eccles_wasm_status_t fn(eccles_wasm_vm_t *vm, uint64_t *slots);
```

- Arguments arrive in `slots[0]`, `slots[1]`, ... as 64-bit values. Convert with `eccles_wasm_to_i32(slots[0])`, `eccles_wasm_to_i64`, `eccles_wasm_to_f32`, `eccles_wasm_to_f64`.
- Put a result in `slots[0]` with `eccles_wasm_from_i32(x)`, `from_i64`, `from_f32`, `from_f64`.
- Return `ECCLES_WASM_SUCCESSFUL`. Any other return value traps the guest with `TRAP_HOST` and fails the current call.

## The signature string

Format `"r(params)"`: the result type first, then the parameter types in brackets.

| Letter | Type |
|---|---|
| `i` | i32 (also pointers, which are offsets into guest memory) |
| `I` | i64 |
| `f` | f32 |
| `F` | f64 |
| `v` | no result (only as the result letter) |

| Signature | C prototype in the guest |
|---|---|
| `"i(ii)"` | `int fn(int, int)` |
| `"v()"` | `void fn(void)` |
| `"v(i)"` | `void fn(int)` |
| `"F(F)"` | `double fn(double)` |
| `"I(Ii)"` | `long long fn(long long, int)` |

If the signature does not match the module's import, load fails with `signature mismatch`. Names are matched exactly (up to `ECCLES_WASM_MAX_NAME`, 48 characters). Up to `ECCLES_WASM_MAX_HOST_FUNCS` (16) functions per instance.

## Reading and writing the guest's memory

Pointers from the guest are offsets into its linear memory. Turn them into a host pointer with `eccles_wasm_vm_mem(vm, offset, length)`. It returns `NULL` if the range is outside the guest's memory: always check.

```c
/* 04b_host_memory.c - a host function that reads the guest's memory and keeps per-instance state. */
#include "eccles_wasm.h"
#include <stdio.h>

typedef struct { const char *name; int reports; } ctx_t;

static eccles_wasm_status_t host_checksum(eccles_wasm_vm_t *vm, uint64_t *slots) {
    uint32_t ptr = (uint32_t)slots[0], len = (uint32_t)slots[1];
    const uint8_t *p = eccles_wasm_vm_mem(vm, ptr, len);        /* NULL when the range is outside the guest's memory */
    if (!p) return ECCLES_WASM_FAILED;                          /* anything but SUCCESSFUL traps the guest (TRAP_HOST) */
    uint32_t sum = 0;
    for (uint32_t i = 0; i < len; i++) sum += p[i];
    slots[0] = eccles_wasm_from_i32((int32_t)sum);
    return ECCLES_WASM_SUCCESSFUL;
}

static eccles_wasm_status_t host_report(eccles_wasm_vm_t *vm, uint64_t *slots) {
    ctx_t *c = (ctx_t *)eccles_wasm_vm_user(vm);                /* the pointer given to eccles_wasm_vm_set_user */
    c->reports++;
    printf("[%s] guest reported code %d (report #%d)\n", c->name, eccles_wasm_to_i32(slots[0]), c->reports);
    return ECCLES_WASM_SUCCESSFUL;                              /* "v(i)": no result, so slots[0] is not written */
}

int main(int argc, char **argv) {
    const char *path = argc > 1 ? argv[1] : "build/wiki/buffer.wasm";
    ctx_t ctx = { "unit-1", 0 };
    uint64_t r[1];

    eccles_wasm_vm_t *vm = eccles_wasm_default_vm();
    eccles_wasm_vm_set_user(vm, &ctx);
    eccles_wasm_register("host_checksum", host_checksum, "i(ii)");
    eccles_wasm_register("host_report", host_report, "v(i)");

    if (eccles_wasm_load(path) != ECCLES_WASM_SUCCESSFUL) return 1;
    eccles_wasm_call("run", NULL, 0, r, 1);
    printf("run() = %d  (sum of i*7 for i < 32 is %d)\n", eccles_wasm_to_i32(r[0]), 7 * 31 * 32 / 2);
    return 0;
}
```
*(file: `examples/wiki/host/04b_host_memory.c`)*

The guest:

```c
/* buffer.c - hand a block of the guest's own memory to the host and get an answer back. */
#include "eccles_wasm_runtime.h"

EW_IMPORT("host_checksum") unsigned host_checksum(const void *data, unsigned len);
EW_IMPORT("host_report")   void     host_report(int code);

static uint8_t data[32];

EW_EXPORT("run") unsigned run(void) {
    for (int i = 0; i < 32; i++) data[i] = (uint8_t)(i * 7);
    unsigned sum = host_checksum(data, sizeof data);       /* the pointer is an offset into the guest's memory */
    host_report((int)sum & 0xFF);
    return sum;
}
```
*(file: `examples/wiki/guest/buffer.c`)*

Output:

```text
[unit-1] guest reported code 144 (report #1)
run() = 3472  (sum of i*7 for i < 32 is 3472)
```

Use the pointer only inside the host function and do not keep it after the function returns.

## State per instance

`eccles_wasm_vm_set_user(vm, ptr)` stores one pointer per instance; `eccles_wasm_vm_user(vm)` reads it back inside the host function. This is how one host function serves several instances ([Instances](Instances)).

## Per-instance registration

`eccles_wasm_register` is for the default instance. For others use `eccles_wasm_vm_register(vm, name, fn, sig)`. Clear all with `eccles_wasm_unregister_all()` or `eccles_wasm_vm_unregister_all(vm)`.

## Rules

- Register before every load that needs the function. A function registered after the load is not linked.
- Do not call `eccles_wasm_call` on the same instance from inside a host function: it returns `busy (re-entrant call)`.
- Keep host functions short. While one runs the guest is paused.
- Host functions are trusted. They are not checked against permissions; if they touch hardware, check what the guest may do yourself, or call the `eccles_wasm_vm_*` privilege API.

## Imported globals

For modules that import globals (some Emscripten-style builds import `__memory_base` or `__stack_pointer`): `eccles_wasm_vm_set_global(vm, "name", value)` before loading. Unset imports start at 0.

## Lenient imports

By default an unresolved import fails the load, so mistakes show up immediately. `-DECCLES_WASM_LENIENT_IMPORTS` makes the load succeed and traps only when the missing import is actually called. Use it for modules with optional functions.

# Permissions (Hardware Privileges)

**A module can touch no hardware until you allow it.** This is the default in v2.0. A new instance can compute, and every hardware import returns `DENIED` (3) without touching the chip. You decide, per instance, which hardware a module may use, and optionally which pins, buses and I2C addresses.

This makes it safe to run code you did not write: a downloaded plugin that was only granted `LOG` and `TIME` cannot drive a relay, whatever it contains.

## The quick way

```c
eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_PIN_ALL | ECCLES_WASM_ALLOW_SAFE);
```

Combine bits with `|`. Call it before or after loading, any time. It applies to the default instance (or `eccles_wasm_vm_set_hal_privilege(vm, bits)` for another one).

## The permission bits

| Constant | Allows |
|---|---|
| `ECCLES_WASM_PERM_GPIO_READ` | `read` |
| `ECCLES_WASM_PERM_GPIO_WRITE` | `enable`, `disable`, `toggle`, `write` |
| `ECCLES_WASM_PERM_GPIO_CONFIG` | `mode` (direction and pulls) |
| `ECCLES_WASM_PERM_ANALOG_OUT` | `analog`, `pwm`, `dac` |
| `ECCLES_WASM_PERM_ADC` | `adc` |
| `ECCLES_WASM_PERM_IRQ` | `irq_attach`, `irq_count`, `irq_clear`, `irq_detach` |
| `ECCLES_WASM_PERM_UART` | `uart_*` |
| `ECCLES_WASM_PERM_I2C` | `i2c_*` |
| `ECCLES_WASM_PERM_SPI` | `spi_*` |
| `ECCLES_WASM_PERM_TIME` | `millis`, `micros`, `sleep`, `sleep_us`, `yield`, WASI `clock_time_get` and `sched_yield` |
| `ECCLES_WASM_PERM_RANDOM` | `random`, WASI `random_get` |
| `ECCLES_WASM_PERM_LOG` | `log` (and therefore `ew_printf`), WASI `fd_write` |
| `ECCLES_WASM_PERM_WDT` | `wdt_feed` |
| `ECCLES_WASM_PERM_POWER` | `deep_sleep`, `reset` (they affect the whole device) |
| `ECCLES_WASM_PERM_THREADS` | `thread-spawn` ([Threads](Threads-and-Spawner)) |

## The presets

| Preset | Contains | Use |
|---|---|---|
| `ECCLES_WASM_ALLOW_NONE` | nothing | the default: pure computation |
| `ECCLES_WASM_ALLOW_SAFE` | `TIME`, `RANDOM`, `LOG` | the module may print, wait, and read the clock |
| `ECCLES_WASM_ALLOW_READ_ONLY` | `GPIO_READ`, `ADC`, plus `SAFE` | sensors only: the module can look, not drive |
| `ECCLES_WASM_ALLOW_PIN_ALL` | all six pin permissions (`GPIO_*`, `ANALOG_OUT`, `ADC`, `IRQ`) | full pin control |
| `ECCLES_WASM_ALLOW_BUSES` | `UART`, `I2C`, `SPI` | communication buses |
| `ECCLES_WASM_ALLOW_ALL` | every permission | your own trusted code, development |

`ALLOW_PIN_ALL` does not include `TIME`: a blink module that sleeps needs `ALLOW_PIN_ALL | ALLOW_SAFE`.

## Limit to specific pins, buses and addresses

Build a policy with `eccles_wasm_privilege_t`, then apply it:

```c
eccles_wasm_privilege_t p;
eccles_wasm_privilege_init(&p, ECCLES_WASM_PERM_GPIO_WRITE | ECCLES_WASM_PERM_I2C | ECCLES_WASM_ALLOW_SAFE);
eccles_wasm_privilege_allow_pin_range(&p, 5, 6);                         // only pins 5 and 6
eccles_wasm_privilege_allow_pin(&p, 13);                                 // and pin 13
eccles_wasm_privilege_allow_bus(&p, ECCLES_WASM_BUS_I2C, 0);             // only I2C bus 0
eccles_wasm_privilege_allow_i2c_addr(&p, 0x48, 0x4B);                    // only these sensor addresses
eccles_wasm_set_privilege(&p);                                           // or eccles_wasm_vm_set_privilege(vm, &p)
```

| Rule | Meaning |
|---|---|
| no `allow_pin*` call | every pin is allowed (if the permission bit is set) |
| first `allow_pin*` call | switches to allow-list mode: only listed pins pass |
| `allow_bus(kind, id)` | restricts that kind (`ECCLES_WASM_BUS_UART`, `_I2C`, `_SPI`) to the listed bus numbers (0..15) |
| `allow_i2c_addr(lo, hi)` | restricts I2C to this 7-bit address range |

In allow-list mode a pin number at or above `ECCLES_WASM_PIN_FILTER_BITS` (256 by default) is always refused, and `allow_pin` for it fails. Raise the macro if your chip's numbering goes higher (STM32 uses `port*16+bit`, Zephyr `port*32+bit`).

## See it work

```c
/* 02_privileges.c - deny by default. The same module, four different policies. */
#include "eccles_wasm.h"
#include <stdio.h>

static void audit(eccles_wasm_vm_t *vm, const char *import_name) {      /* called for every refused call */
    (void)vm;
    printf("   [audit] refused: %s\n", import_name);
}

int main(int argc, char **argv) {
    const char *path = argc > 1 ? argv[1] : "build/wiki/led.wasm";
    eccles_wasm_vm_t *vm = eccles_wasm_default_vm();
    uint64_t r[1];

    eccles_wasm_vm_set_denied_hook(vm, audit);
    eccles_wasm_load(path);

    puts("1) default policy (nothing granted):");
    eccles_wasm_call("led_on", NULL, 0, r, 1);
    printf("   led_on() returned %d (3 = DENIED); pin 2 level = %u\n", (int)r[0], (unsigned)eccles_wasm_sim_pin_level(2));

    puts("2) grant GPIO write:");
    eccles_wasm_set_hal_privilege(ECCLES_WASM_PERM_GPIO_WRITE);
    eccles_wasm_call("led_on", NULL, 0, r, 1);
    printf("   led_on() returned %d (0 = OK);     pin 2 level = %u\n", (int)r[0], (unsigned)eccles_wasm_sim_pin_level(2));

    puts("3) only pin 5 and 6 may be used:");
    eccles_wasm_privilege_t p;
    eccles_wasm_privilege_init(&p, ECCLES_WASM_PERM_GPIO_WRITE);
    eccles_wasm_privilege_allow_pin_range(&p, 5, 6);
    eccles_wasm_set_privilege(&p);
    eccles_wasm_call("led_off", NULL, 0, r, 1);
    printf("   led_off() on pin 2 returned %d (3 = DENIED)\n", (int)r[0]);

    puts("4) everything:");
    eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_ALL);
    eccles_wasm_call("led_off", NULL, 0, r, 1);
    printf("   led_off() returned %d (0 = OK)\n", (int)r[0]);

    printf("refused calls so far: %u, last refused: %s\n", (unsigned)eccles_wasm_denied_count(), eccles_wasm_last_denied());
    return 0;
}
```
*(file: `examples/wiki/host/02_privileges.c`)*

Output:

```text
1) default policy (nothing granted):
   [audit] refused: enable
   led_on() returned 3 (3 = DENIED); pin 2 level = 0
2) grant GPIO write:
   led_on() returned 0 (0 = OK);     pin 2 level = 1
3) only pin 5 and 6 may be used:
   [audit] refused: disable
   led_off() on pin 2 returned 3 (3 = DENIED)
4) everything:
   led_off() returned 0 (0 = OK)
refused calls so far: 2, last refused: disable
```

Notice that a refused call returns `3` to the guest, the pin level stays `0`, and the audit hook sees every refusal.

## Audit

```c
static void on_denied(eccles_wasm_vm_t *vm, const char *import_name) {
    printf("module tried: %s\n", import_name);
}
eccles_wasm_vm_set_denied_hook(vm, on_denied);

eccles_wasm_denied_count();     // refused calls so far (default instance)
eccles_wasm_last_denied();      // name of the last refused import, "" if none
```

The per-instance versions are `eccles_wasm_vm_denied_count(vm)` and `eccles_wasm_vm_last_denied(vm)`. The hook runs inside the refused call: keep it short and do not call back into the runtime.

## What is and is not checked

- **Checked:** every import a guest calls that reaches hardware, including the WASI ones and `thread-spawn`.
- **Not checked:** your own C code. `eccles_wasm_enable(5)` called from your firmware is trusted. Host functions you register are trusted too ([Host Functions](Host-Functions)).
- **Order:** the permission check runs before anything else. A refused call never calls the backend and does not touch the pin, bus or device.
- **WASI:** a refused WASI call returns the WASI error `ENOTCAPABLE` (76) to the guest instead of 3.

## Change the default

`-DECCLES_WASM_DEFAULT_PRIVILEGE=ECCLES_WASM_ALLOW_ALL` makes new instances trusted (the v1.x behaviour). Only do that when you control all the code that will ever run.

## Patterns

| Situation | Policy |
|---|---|
| user-uploaded plugin that may print and wait | `ALLOW_SAFE` |
| sensor-reading app | `ALLOW_READ_ONLY` |
| actuator app on one relay pin | `PERM_GPIO_WRITE`, `PERM_GPIO_CONFIG`, `PERM_TIME`, `allow_pin(&p, RELAY_PIN)` |
| I2C temperature app | `PERM_I2C`, `PERM_TIME`, `allow_bus(I2C, 0)`, `allow_i2c_addr(0x48, 0x4B)` |
| your own firmware module | `ALLOW_ALL` |
| two apps, different rights | two instances ([Instances](Instances)), a policy each |

## Troubleshooting

| Symptom | Cause |
|---|---|
| everything returns 3, nothing happens | no privilege was set: add `eccles_wasm_set_hal_privilege(...)` |
| `ew_printf` prints nothing | needs `PERM_LOG` (in `ALLOW_SAFE`) |
| `sleep` returns 3 and the loop spins | needs `PERM_TIME` (in `ALLOW_SAFE`) |
| the pin works but `mode` is denied | add `PERM_GPIO_CONFIG` |
| the allowed pin is still denied | the pin number differs from the platform's numbering ([Platforms Overview](Platforms-Overview)) |
| the guest sees `-1` from `thread-spawn` | needs `PERM_THREADS` and a spawner |

# Instances: several modules at once

The handle-free API (`eccles_wasm_load`, `eccles_wasm_call`, ...) works on one built-in **default instance**. When you need two modules at once, with separate memory, separate permissions and separate host functions, create instances.

An instance is an independent sandbox. It has its own arena, module, privileges, fuel, host functions and error state.

## Create and use

```c
static uint8_t arena_a[96 * 1024] __attribute__((aligned(8)));
eccles_wasm_vm_t *a = eccles_wasm_vm_create(arena_a, sizeof arena_a);     // over memory you provide
eccles_wasm_vm_t *b = eccles_wasm_vm_create_heap(96 * 1024);              // or from the heap (when USE_HEAP is on)

eccles_wasm_vm_set_hal_privilege(a, ECCLES_WASM_ALLOW_PIN_ALL | ECCLES_WASM_ALLOW_SAFE);
eccles_wasm_vm_set_hal_privilege(b, ECCLES_WASM_ALLOW_READ_ONLY);         // b may only look

eccles_wasm_vm_load_buffer(a, motor_wasm, motor_wasm_len);
eccles_wasm_vm_load_buffer(b, sensor_wasm, sensor_wasm_len);

eccles_wasm_vm_call(a, "run", NULL, 0, NULL, 0);
eccles_wasm_vm_destroy(b);                                                // frees a heap arena
```

Every default-instance function has an `eccles_wasm_vm_*` twin taking the instance first: `vm_load`, `vm_load_buffer`, `vm_load_stream`, `vm_unload`, `vm_call`, `vm_run`, `vm_has_export`, `vm_set_fuel`, `vm_last_error`, `vm_last_error_info`, `vm_last_error_str`, `vm_get_stats`, `vm_register`, `vm_unregister_all`, `vm_set_privilege`, `vm_set_hal_privilege`, `vm_denied_count`, `vm_last_denied`, `vm_mem`, `vm_mem_size`, `vm_exited`. `eccles_wasm_default_vm()` returns the built-in one, so you can mix both styles.

`eccles_wasm_vm_create` needs at least 4 KB beyond the instance struct (about 1.2 KB of your arena). It returns `NULL` when the memory is too small or the pointer is `NULL`.

## Running instances in parallel

- **One instance, one task at a time.** Never call into the same instance from two tasks. A second call returns `busy (re-entrant call)`.
- **Different instances, different tasks: fine.** There are no globals in the interpreter.
- **The chip is shared.** Two tasks driving the same pin or bus need a lock. Define `ECCLES_WASM_HW_LOCK()` and `ECCLES_WASM_HW_UNLOCK()` (a recursive mutex). The runtime takes it around every short hardware operation. `sleep` and `uart_read` never hold it.

FreeRTOS:

```c
extern SemaphoreHandle_t g_hw_mx;
#define ECCLES_WASM_HW_LOCK()    xSemaphoreTakeRecursive(g_hw_mx, portMAX_DELAY)
#define ECCLES_WASM_HW_UNLOCK()  xSemaphoreGiveRecursive(g_hw_mx)
/* once at start-up: g_hw_mx = xSemaphoreCreateRecursiveMutex(); */
```

Zephyr: `k_mutex_lock(&hw_mx, K_FOREVER)` and `k_mutex_unlock(&hw_mx)` (Zephyr mutexes are recursive). Desktop: `-pthread -DECCLES_WASM_THREADSAFE` gives you a built-in pthread mutex.

## Per-instance state in host functions

```c
eccles_wasm_vm_set_user(vm, &my_context);        // any pointer
...
static eccles_wasm_status_t host_fn(eccles_wasm_vm_t *vm, uint64_t *slots) {
    my_context_t *c = eccles_wasm_vm_user(vm);   // which instance called me?
```

See [Host Functions](Host-Functions).

## Isolation

Instances share nothing but the chip and the global file-system hook (`set_fs`). A trap, an exhausted fuel budget or a bad memory access in one instance does not affect another. The conformance suite checks this on real hardware: isolation, concurrent instances, create and destroy leaks, and arena sizing ([Validation](Validation)).

## Example: two instances, different rights

The repository's `examples/multi_instance/main.c` runs one module twice on two threads, one with full pin rights and one read-only, so the second one's blinking is refused:

```bash
make examples && build/example_multi examples/blink.wasm
```

## Memory budget

Each instance needs its own arena: its module, code, stacks and memory. Two stock modules need about 2 x 75 KB. Use `MEM_LIMIT_BYTES` and small guest memories to fit more ([Memory Sizing](Memory-Sizing)).

# Threads and the Spawner

A guest can start threads (the WebAssembly "wasi-threads" model): several instances run the same code over **one shared memory**, and the guest coordinates with atomics.

**The runtime does not create threads. You do.** When the guest asks for a thread, the runtime calls a function you provide, the **spawner**. The spawner creates a task in your RTOS. This keeps the runtime portable: FreeRTOS, Zephyr, ThreadX, bare-metal schedulers and POSIX threads all work.

## What you need

| Piece | Where | Value |
|---|---|---|
| Atomics + threads compiled in | build flags | `-DECCLES_WASM_ATOMICS=1 -DECCLES_WASM_THREADS=1` |
| A hardware lock | build flags or config | `ECCLES_WASM_HW_LOCK()` and `ECCLES_WASM_HW_UNLOCK()` (needed if threads touch pins/buses) |
| Permission | host code | `ECCLES_WASM_PERM_THREADS` |
| A spawner | host code | `eccles_wasm_vm_set_thread_spawner(vm, fn, ctx)` |
| A threaded guest | guest build | built with shared memory and atomics (below) |

If any piece is missing, `thread-spawn` returns -1 inside the guest, which is how the guest learns that it cannot have threads. It never crashes.

## The spawner in four steps

The runtime calls `int32_t spawner(eccles_wasm_vm_t *parent, uint32_t start_arg, void *ctx)` when the guest spawns. It must:

1. Allocate an arena for the child.
2. `child = eccles_wasm_vm_spawn(parent, arena, size)`. The child shares code and memory with the parent and inherits its privileges.
3. Start an RTOS task that runs `eccles_wasm_vm_thread_start(child, tid, start_arg)` and then `eccles_wasm_vm_destroy(child)`.
4. Return a positive thread id, or `-1` to refuse (the guest sees the -1).

### Desktop (POSIX threads), runnable

```c
/* 07_threads.c - run a wasm module that starts its own threads. Your job: provide the spawner (here: POSIX threads).
 * On an MCU the spawner creates an RTOS task instead - the shape is identical (see the Threads wiki page). */
#include "eccles_wasm.h"
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>

#define MAX_THREADS 8
#define CHILD_ARENA (48 * 1024)

typedef struct { eccles_wasm_vm_t *vm; void *arena; int32_t tid; uint32_t arg; } child_t;
static pthread_t g_threads[MAX_THREADS]; static int g_count;
static int32_t g_next_tid = 1;
static pthread_mutex_t g_lock = PTHREAD_MUTEX_INITIALIZER;

static void *child_main(void *p) {                                   /* the body of the new thread / RTOS task */
    child_t *c = (child_t *)p;
    eccles_wasm_vm_thread_start(c->vm, c->tid, c->arg);              /* runs the module's wasi_thread_start(tid, arg) */
    eccles_wasm_vm_destroy(c->vm);                                   /* ALWAYS destroy the child when it is done */
    free(c->arena); free(c);
    return NULL;
}

/* called by the runtime when the guest calls thread-spawn(start_arg). Return a thread id > 0, or -1 to refuse. */
static int32_t my_spawner(eccles_wasm_vm_t *parent, uint32_t start_arg, void *ctx) {
    (void)ctx;
    pthread_mutex_lock(&g_lock);
    if (g_count >= MAX_THREADS) { pthread_mutex_unlock(&g_lock); return -1; }
    child_t *c = (child_t *)malloc(sizeof *c);
    c->arena = malloc(CHILD_ARENA);                                  /* each child needs its own arena (stacks + tables) */
    c->vm = eccles_wasm_vm_spawn(parent, c->arena, CHILD_ARENA);     /* sibling: shares code + linear memory + privilege */
    if (!c->vm) { free(c->arena); free(c); pthread_mutex_unlock(&g_lock); return -1; }
    c->tid = g_next_tid++; c->arg = start_arg;
    pthread_create(&g_threads[g_count++], NULL, child_main, c);
    pthread_mutex_unlock(&g_lock);
    return c->tid;
}

int main(int argc, char **argv) {
    const char *path = argc > 1 ? argv[1] : "build/wiki/threads.wasm";
    eccles_wasm_vm_t *vm = eccles_wasm_vm_create_heap(200 * 1024);
    uint64_t a[1] = { 4 }, r[1];

    eccles_wasm_vm_set_hal_privilege(vm, ECCLES_WASM_PERM_THREADS | ECCLES_WASM_PERM_TIME);   /* 1. permission to spawn */
    eccles_wasm_vm_set_thread_spawner(vm, my_spawner, NULL);                                  /* 2. the spawner */
    eccles_wasm_vm_set_fuel(vm, 0);

    if (eccles_wasm_vm_load(vm, path) != ECCLES_WASM_SUCCESSFUL) {
        printf("load failed: %s\n", eccles_wasm_error_name(eccles_wasm_vm_last_error(vm)));
        return 1;
    }
    if (eccles_wasm_vm_call(vm, "run", a, 1, r, 1) == ECCLES_WASM_SUCCESSFUL)
        printf("4 workers x 1000 increments = %d\n", (int)eccles_wasm_to_i32(r[0]));
    else
        printf("run failed: %s\n", eccles_wasm_error_name(eccles_wasm_vm_last_error(vm)));

    for (int i = 0; i < g_count; i++) pthread_join(g_threads[i], NULL);

    /* without the permission, or without a spawner, thread-spawn just returns -1 inside the guest */
    eccles_wasm_vm_set_hal_privilege(vm, ECCLES_WASM_PERM_TIME);
    eccles_wasm_vm_call(vm, "run", a, 1, r, 1);
    printf("without PERM_THREADS the guest sees %d\n", (int)eccles_wasm_to_i32(r[0]));
    eccles_wasm_vm_destroy(vm);
    return 0;
}
```
*(file: `examples/wiki/host/07_threads.c`)*

Output:

```text

without PERM_THREADS the guest sees -1
```

The guest that runs it (`examples/wiki/guest/threads.c`):

```c
/* threads.c - spawn N worker threads that all add to ONE counter in shared memory (wasi-threads model). */
#include "eccles_wasm_runtime.h"

#define MAX_WORKERS 4
#define STACK 2048
__attribute__((import_module("wasi"), import_name("thread-spawn"))) int thread_spawn(void *start_arg);

static volatile uint32_t counter, finished;
static uint8_t stacks[MAX_WORKERS][STACK] __attribute__((aligned(16)));   /* one private stack per worker */

/* every worker enters here, in its own instance, with its own globals */
__attribute__((export_name("wasi_thread_start"), noinline)) void wasi_thread_start(int tid, int slot) {
    uint32_t sp = (uint32_t)(uintptr_t)&stacks[(uint32_t)slot][STACK];
    __asm__ volatile(".globaltype __stack_pointer, i32\n\tlocal.get %0\n\tglobal.set __stack_pointer" :: "r"(sp));   /* give this worker its own stack */
    (void)tid;
    for (int i = 0; i < 1000; i++) __atomic_fetch_add(&counter, 1, __ATOMIC_SEQ_CST);
    __atomic_fetch_add(&finished, 1, __ATOMIC_SEQ_CST);
}

/* returns the final counter, or a negative number when a thread could not be started */
EW_EXPORT("run") int run(int workers) {
    int started = 0;
    if (workers > MAX_WORKERS) workers = MAX_WORKERS;
    for (int i = 0; i < workers; i++) {
        int tid = thread_spawn((void *)(uintptr_t)i);
        if (tid <= 0) return -(i + 1);      /* -1: even the first spawn failed (no permission, no spawner, no memory) */
        started++;
    }
    while (__atomic_load_n(&finished, __ATOMIC_SEQ_CST) < (uint32_t)started) ew_yield();
    return (int)__atomic_load_n(&counter, __ATOMIC_SEQ_CST);
}
```
*(file: `examples/wiki/guest/threads.c`)*

  -Wl,--shared-memory -Wl,--import-memory -Wl,--initial-memory=65536 -Wl,--max-memory=65536 \

### FreeRTOS (ESP-IDF, STM32Cube FreeRTOS, Pico FreeRTOS)

The same shape with `xTaskCreate`. The ESP32 conformance suite ran this pattern on both cores, with spawn limits, trap isolation and per-thread privileges ([Validation](Validation), phase H):

```c
/* freertos_spawner.c - the thread spawner for FreeRTOS (ESP-IDF, STM32Cube FreeRTOS, Pico FreeRTOS, nRF with FreeRTOS).
 * The same shape, one RTOS task per wasm thread, ran on a real ESP32 in the validation suite.
 *
 * eccles_wasm_config.h needs:
 *   #define ECCLES_WASM_ATOMICS  1
 *   #define ECCLES_WASM_THREADS  1
 *   #define ECCLES_WASM_HW_LOCK()    xSemaphoreTakeRecursive(g_hw_mx, portMAX_DELAY)
 *   #define ECCLES_WASM_HW_UNLOCK()  xSemaphoreGiveRecursive(g_hw_mx)
 */
#include "FreeRTOS.h"
#include "task.h"
#include "eccles_wasm.h"
#include <stdlib.h>

#define MAX_THREADS      4          /* how many wasm threads may run at once */
#define CHILD_ARENA      (8 * 1024) /* bytes each thread's instance gets: its stacks and tables (memory is shared) */
#define CHILD_STACK      8192       /* stack depth of the task that runs the interpreter: bytes on ESP-IDF (8192 ran on the ESP32), words on other FreeRTOS ports */

typedef struct { eccles_wasm_vm_t *vm; void *arena; int32_t tid; uint32_t arg; } child_t;

static volatile uint32_t g_live;
static volatile int32_t g_next_tid;

static void child_task(void *p) {
    child_t c = *(child_t *)p;
    free(p);
    eccles_wasm_vm_thread_start(c.vm, c.tid, c.arg);      /* runs wasi_thread_start(tid, arg) in the guest */
    eccles_wasm_vm_destroy(c.vm);                         /* always destroy the child instance */
    free(c.arena);
    __atomic_fetch_sub(&g_live, 1, __ATOMIC_SEQ_CST);
    vTaskDelete(NULL);
}

/* Called by the runtime when the guest calls thread-spawn(start_arg). Return a thread id > 0, or -1 to refuse. */
int32_t my_spawner(eccles_wasm_vm_t *parent, uint32_t start_arg, void *ctx) {
    (void)ctx;
    if (__atomic_load_n(&g_live, __ATOMIC_SEQ_CST) >= MAX_THREADS) return -1;
    child_t *c = (child_t *)malloc(sizeof *c);
    if (!c) return -1;
    c->arena = malloc(CHILD_ARENA);
    if (!c->arena) { free(c); return -1; }
    c->vm = eccles_wasm_vm_spawn(parent, c->arena, CHILD_ARENA);
    if (!c->vm) { free(c->arena); free(c); return -1; }
    c->tid = __atomic_add_fetch(&g_next_tid, 1, __ATOMIC_SEQ_CST);
    c->arg = start_arg;
    __atomic_add_fetch(&g_live, 1, __ATOMIC_SEQ_CST);
    if (xTaskCreate(child_task, "wasm_thr", CHILD_STACK, c, tskIDLE_PRIORITY + 1, NULL) != pdPASS) {
        __atomic_sub_fetch(&g_live, 1, __ATOMIC_SEQ_CST);
        eccles_wasm_vm_destroy(c->vm);
        free(c->arena);
        free(c);
        return -1;
    }
    return c->tid;
}

/* In app_main() / main(), once, before you run the module:
 *
 *   eccles_wasm_vm_t *vm = eccles_wasm_default_vm();
 *   eccles_wasm_set_hal_privilege(ECCLES_WASM_PERM_THREADS | ECCLES_WASM_ALLOW_SAFE);
 *   eccles_wasm_vm_set_thread_spawner(vm, my_spawner, NULL);
 */
void install_spawner(void) {
    eccles_wasm_vm_t *vm = eccles_wasm_default_vm();
    eccles_wasm_set_hal_privilege(ECCLES_WASM_PERM_THREADS | ECCLES_WASM_ALLOW_SAFE);
    eccles_wasm_vm_set_thread_spawner(vm, my_spawner, NULL);
}
```
*(file: `examples/wiki/host/freertos_spawner.c`)*

Create the hardware mutex once: `g_hw_mx = xSemaphoreCreateRecursiveMutex();`

### Zephyr

```c
#define MAX_THREADS 4
#define CHILD_ARENA (8 * 1024)
K_THREAD_STACK_ARRAY_DEFINE(thr_stacks, MAX_THREADS, 4096);
static struct k_thread thr[MAX_THREADS];
static uint8_t arenas[MAX_THREADS][CHILD_ARENA] __aligned(8);
static eccles_wasm_vm_t *child_vm[MAX_THREADS];
static uint32_t child_arg[MAX_THREADS]; static int32_t child_tid[MAX_THREADS];
static atomic_t used;

static void child_entry(void *p1, void *p2, void *p3) {
    int i = (int)(intptr_t)p1;
    eccles_wasm_vm_thread_start(child_vm[i], child_tid[i], child_arg[i]);
    eccles_wasm_vm_destroy(child_vm[i]);
    atomic_clear_bit(&used, i);
}

static int32_t spawner(eccles_wasm_vm_t *parent, uint32_t start_arg, void *ctx) {
    for (int i = 0; i < MAX_THREADS; i++) {
        if (atomic_test_and_set_bit(&used, i)) continue;               /* slot busy */
        child_vm[i] = eccles_wasm_vm_spawn(parent, arenas[i], CHILD_ARENA);
        if (!child_vm[i]) { atomic_clear_bit(&used, i); return -1; }
        child_arg[i] = start_arg; child_tid[i] = i + 1;
        k_thread_create(&thr[i], thr_stacks[i], K_THREAD_STACK_SIZEOF(thr_stacks[i]),
                        child_entry, (void *)(intptr_t)i, NULL, NULL, 5, 0, K_NO_WAIT);
        return child_tid[i];
    }
    return -1;                                                          /* no free slot */
}
```

This Zephyr version follows the same contract as the validated FreeRTOS one; it has not been run on hardware.

### Other RTOSes and bare metal

Any scheduler works as long as the spawner (a) gives the child its own arena, (b) starts something that calls `eccles_wasm_vm_thread_start(child, tid, start_arg)` and then `eccles_wasm_vm_destroy(child)`, and (c) returns the id. A cooperative scheduler can run `thread_start` as a queued job.

## Rules

- **The parent must outlive its children.** Do not unload, reload or destroy the parent instance while any child still runs. Join first (the desktop example joins every pthread).
- **One spawner call, one child.** Count your children and return -1 at a limit: you control how many threads the chip can afford.
- **Child arena:** it holds the child's value stack and call frames, tables and globals. Shared memory is the parent's. 8 KB was enough for the validation guests; raise it for deep recursion or a large `ECCLES_WASM_VALUE_STACK_SLOTS`.
- **Child task stack:** the interpreter runs on the task's C stack: give it a few KB (4 to 8 KB on 32-bit chips).
- **Privileges:** the child inherits the parent's at spawn time. To narrow it: `eccles_wasm_vm_set_hal_privilege(child, narrower)` inside the spawner, before starting the task.
- **Each child has its own globals** (restored to their state after load), so give each worker its own stack pointer, as `threads.c` does. This is the one thing a threaded guest built without wasi-libc must do itself; wasi-sdk's `wasm32-wasi-threads` target does it for you.
- **Traps are isolated:** a trap in a child ends that child only and does not kill the parent. Check `eccles_wasm_vm_last_error(child)` before destroying it if you care.
- **Waiting:** `memory.atomic.wait` polls, it does not put the task to sleep. A guest should call `ew_yield()` in its wait loops so other tasks run.
- **Memory must be shared:** the module must declare shared memory. Unshared memory with atomic wait is a `TRAP_ATOMIC`.

## Per-thread hardware

All threads use the same chip, so lock it ([Instances](Instances#running-instances-in-parallel)). The runtime holds the lock only for short non-blocking operations.

## Troubleshooting

| Symptom | Cause |
|---|---|
| `thread-spawn` returns -1 in the guest | missing `PERM_THREADS`, no spawner installed, the spawner returned -1 (limit, no memory), or the build lacks `ECCLES_WASM_THREADS=1` |
| load fails with `unsupported WebAssembly feature` | the build lacks `ECCLES_WASM_ATOMICS=1` while the guest uses atomics or shared memory |
| `unresolved import "thread-spawn"` | the build lacks `ECCLES_WASM_THREADS=1` |
| children crash with a stack overflow trap | the child arena or `VALUE_STACK_SLOTS` is too small |
| the whole chip hangs | children spin without `ew_yield()` on a cooperative scheduler, or the parent was destroyed first |
| random wrong data between threads | threads touch the same memory without atomics (a guest bug), or workers share one C stack (give each its own) |
| a pin glitches under threads | no `ECCLES_WASM_HW_LOCK` defined |

# Atomics and Shared Memory

Optional support for the WebAssembly threads proposal: atomic memory instructions (`i32.atomic.load`, `i32.atomic.rmw.add`, `memory.atomic.wait32`, ...) and shared memory. Off by default, because most modules do not need it and the dispatch is slightly bigger.

## Turn it on

```
-DECCLES_WASM_ATOMICS=1
```

Needs a compiler with `__atomic` builtins (GCC and Clang) and a little-endian target (every supported chip). Add `-DECCLES_WASM_THREADS=1` as well if the guest spawns threads ([Threads and the Spawner](Threads-and-Spawner)).

## What you get

- All atomic instructions of the threads proposal: loads, stores, read-modify-write (`add`, `sub`, `and`, `or`, `xor`, `xchg`, `cmpxchg`) in 8, 16, 32 and 64-bit widths, `memory.atomic.notify`, `memory.atomic.wait32`, `memory.atomic.wait64` and `atomic.fence`. The hardware conformance suite checks all 1960 opcode cases on a real ESP32.
- Shared memory declarations (`shared` flag with a maximum).
- Traps: an unaligned atomic access, or a wait on memory that is not shared, ends the call with `TRAP_ATOMIC` ("trap: unaligned atomic access or wait on unshared memory").
- `memory.atomic.wait` polls (it yields to your scheduler between checks) instead of putting the task to sleep, which works on every RTOS and on bare metal.

## When atomics are enough on their own

A single instance can use atomics without threads: for example a module that shares state with another module through the host. Most users who enable `ATOMICS` also enable `THREADS`.

## Guest side

Clang flags for a guest that uses atomics and shared memory:

```bash
clang --target=wasm32 -matomics -mbulk-memory -mmutable-globals -O2 -nostdlib -ffreestanding \
  -Wl,--no-entry -Wl,--export-all -Wl,-z,stack-size=4096 \
  -Wl,--shared-memory -Wl,--import-memory -Wl,--initial-memory=65536 -Wl,--max-memory=65536 \
  -Isdk/c -o app.wasm app.c
```

`__atomic_fetch_add`, `__atomic_load_n`, `__atomic_compare_exchange_n` and friends compile to the wasm atomic instructions. `_Atomic` types work the same way.

```c
static volatile uint32_t counter;
EW_EXPORT("bump") void bump(void) { __atomic_fetch_add(&counter, 1, __ATOMIC_SEQ_CST); }
```

## Errors

| Symptom | Cause |
|---|---|
| load fails: `unsupported WebAssembly feature`, info `0x3103` or similar | the guest uses atomics but the build lacks `ECCLES_WASM_ATOMICS=1`. The info value is the offending opcode |
| `trap: unaligned atomic access or wait on unshared memory` | the address is not a multiple of the access size, or `wait` was used on non-shared memory |
| garbage between threads | non-atomic accesses to shared data: use atomics or a lock in the guest |

# Safety: Sandbox, Fuel and Traps

Running code you did not write on a microcontroller needs three guarantees: it cannot corrupt your firmware, it cannot run forever, and a fault does not take the device down. Eccles WASM gives all three.

## The sandbox

- The guest only sees its own linear memory. Every load and store is bounds-checked. A wild pointer ends the call with a trap and the chip carries on.
- Function calls go through typed tables: calling through a wrong pointer type traps (`indirect call type mismatch`).
- The guest's value stack and call depth are bounded (`ECCLES_WASM_VALUE_STACK_SLOTS`, `ECCLES_WASM_CALL_DEPTH`). Runaway recursion traps with a stack or call-depth error.
- The guest cannot reach hardware except through the imports you permit ([Permissions](Permissions)).
- The loader validates the module's structure before running a single instruction, and rejects malformed modules with a byte offset. A truncated or otherwise malformed file is refused, not executed. The conformance suite throws truncated and mutated modules at a real ESP32 and requires that the chip never crashes ([Validation](Validation), phase F).

What the loader does **not** do: it checks structure, not operand types. Use toolchains you trust to emit valid wasm (clang, rustc, wasm-opt), and authenticate modules you download (hash or signature) before loading.

## Fuel: stop endless loops

```c
eccles_wasm_set_fuel(1000000);        // every call gets a budget of 1,000,000 units
```

A budget counts calls and backward branches, one unit each. When it runs out the call ends with `TRAP_FUEL` ("trap: instruction budget exhausted") and the instance stays usable. `0` means unlimited. The budget applies to each `eccles_wasm_call`, it is not shared across calls.

```c
/* 05_fuel_and_traps.c - a bad guest cannot hurt the host: infinite loops, divide by zero, wild pointers. */
#include "eccles_wasm.h"
#include <stdio.h>

static void report(const char *what, eccles_wasm_status_t st) {
    printf("%-28s -> status %d, error %s\n", what, (int)st, eccles_wasm_error_name(eccles_wasm_last_error()));
}

int main(int argc, char **argv) {
    const char *dir = argc > 1 ? argv[1] : "build/wiki";
    char path[256]; uint64_t a[2], r[1];

    /* ---- fuel: stop endless loops ---- */
    snprintf(path, sizeof path, "%s/forever.wasm", dir);
    eccles_wasm_load(path);
    eccles_wasm_set_fuel(100000);                         /* backward branches and calls cost 1 each, 0 = unlimited */
    report("spin() with 100000 fuel", eccles_wasm_run("spin"));
    report("quick() afterwards", eccles_wasm_call("quick", NULL, 0, r, 1));
    printf("quick() = %d - the instance is still healthy\n", (int)eccles_wasm_to_i32(r[0]));

    /* ---- traps ---- */
    snprintf(path, sizeof path, "%s/crash.wasm", dir);
    eccles_wasm_load(path);
    a[0] = 10; a[1] = 0;
    report("div(10, 0)", eccles_wasm_call("div", a, 2, r, 1));
    a[0] = 100000;
    report("oob(100000)", eccles_wasm_call("oob", a, 1, r, 1));
    report("boom()", eccles_wasm_run("boom"));
    a[0] = 10; a[1] = 2;
    report("div(10, 2)", eccles_wasm_call("div", a, 2, r, 1));
    printf("div(10, 2) = %d\n", (int)eccles_wasm_to_i32(r[0]));

    /* ---- API misuse is an error code too ---- */
    report("call a missing export", eccles_wasm_run("does_not_exist"));
    report("wrong argument count", eccles_wasm_call("div", a, 1, r, 1));
    eccles_wasm_unload();
    report("call with nothing loaded", eccles_wasm_run("div"));
    return 0;
}
```
*(file: `examples/wiki/host/05_fuel_and_traps.c`)*

Output:

```text
spin() with 100000 fuel      -> status 1, error trap: instruction budget exhausted
quick() afterwards           -> status 0, error ok
quick() = 42 - the instance is still healthy
div(10, 0)                   -> status 1, error trap: integer divide by zero
oob(100000)                  -> status 1, error trap: out-of-bounds memory access
boom()                       -> status 1, error trap: unreachable
div(10, 2)                   -> status 0, error ok
div(10, 2) = 5
call a missing export        -> status 1, error no such export
wrong argument count         -> status 1, error signature mismatch
call with nothing loaded     -> status 1, error no module loaded
```

Choosing a number: run your real module once with a large budget and measure, then set the limit to a few times the normal need. A `loop()` that blinks and sleeps costs very little fuel because `sleep` is a single call. A busy computation (a CRC over a few KB) costs about one unit per loop iteration.

Fuel is compiled in by default (`ECCLES_WASM_FUEL 1`). For maximum speed on code you fully trust, build with `-DECCLES_WASM_FUEL=0`: the check disappears and `set_fuel` does nothing ([Speed Tuning](Speed-Tuning)).

## Yielding and watchdogs

Every `ECCLES_WASM_YIELD_INTERVAL` back-branches and calls (4096 by default, a power of two) the runtime calls `ECCLES_WASM_YIELD()`, which you can define to feed a watchdog or let the scheduler run:

```c
#define ECCLES_WASM_YIELD_INTERVAL  4096
#define ECCLES_WASM_YIELD()         vTaskDelay(0)
```

This is what keeps a long computation from tripping a task watchdog without fuel. The guest can also call `ew_yield()` or `ew_sleep()`.

## Traps

A trap ends the current call. The call returns `ECCLES_WASM_FAILED`, `eccles_wasm_last_error()` tells which trap, and the instance is still loaded and callable.

| Trap | Typical cause |
|---|---|
| `unreachable` | `__builtin_trap()`, a Rust panic, an `abort()` |
| `out-of-bounds memory access` | wild or stale pointer; access beyond `MEM_LIMIT_BYTES` |
| `integer divide by zero` | `x / 0` |
| `integer overflow` | `INT_MIN / -1` |
| `invalid conversion to integer` | float NaN or out of range to int (use the saturating forms) |
| `undefined table element` | calling an empty function-pointer slot |
| `indirect call type mismatch` | function pointer with the wrong signature |
| `value stack overflow` | too many locals or deep expressions: raise `ECCLES_WASM_VALUE_STACK_SLOTS` |
| `call stack overflow` | recursion too deep: raise `ECCLES_WASM_CALL_DEPTH` |
| `instruction budget exhausted` | fuel ran out |
| `host function failed` | one of your host functions returned something other than SUCCESSFUL |
| `out-of-bounds table access` | table.get / table.set / table.copy with a bad index |
| `unaligned atomic access ...` | see [Atomics](Atomics) |

A guest overflowing its own C stack is not reported as a stack trap: it either corrupts the guest's own data or ends in an out-of-bounds trap. It cannot reach your firmware, but size `-Wl,-z,stack-size` generously for recursive code.

## A safe way to run an untrusted module

```c
eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_SAFE);   // no pins, no buses
eccles_wasm_set_fuel(500000);                            // no endless loops
// load it from an authenticated source, then:
if (eccles_wasm_call("run", NULL, 0, r, 1) != ECCLES_WASM_SUCCESSFUL) {
    log_error(eccles_wasm_error_name(eccles_wasm_last_error()));
    eccles_wasm_unload();                                // drop it, carry on
}
```

Arena exhaustion is also contained: loading a module that is too big fails with `out of arena memory` and leaves the device untouched.

## After a trap

Call again, or unload and load a fresh copy. The guest's own state (globals, memory) is whatever it was when the trap happened. If the module keeps its own invariants in memory, reload it after a trap to start clean.

## Ready-made configurations

**Fastest** (trusted code, ESP32 or Pico):

```
-DECCLES_WASM_FUEL=0 -DECCLES_WASM_EXEC_IRAM=1
```

**Smallest RAM** (a tiny module on a 32 KB chip):

```
-DECCLES_WASM_ARENA_SIZE=(16ul*1024ul) -DECCLES_WASM_MEM_LIMIT_BYTES=(2ul*1024ul)
-DECCLES_WASM_VALUE_STACK_SLOTS=128 -DECCLES_WASM_CHUNK_SIZE=64
```

**Untrusted plugins** (defaults are already safe): keep `FUEL=1`, deny-all privileges, and set `eccles_wasm_set_fuel()` for every call.

**Threads**:

```
-DECCLES_WASM_ATOMICS=1 -DECCLES_WASM_THREADS=1
```

plus `ECCLES_WASM_HW_LOCK()` and `ECCLES_WASM_HW_UNLOCK()` and a spawner.

**Trusted development build** (the old v1.x behaviour):

```
-DECCLES_WASM_DEFAULT_PRIVILEGE=ECCLES_WASM_ALLOW_ALL
```

**No floats** (chips without an FPU where you do not need floats): `-DECCLES_WASM_NO_FLOAT`.

**Portable dispatch** (compilers without computed goto): `-DECCLES_WASM_NO_COMPUTED_GOTO`.

# Memory Sizing

Everything lives in one **arena**. Size it once and loading can never fall over a surprise `malloc`.

## What the arena holds

```
 ┌────────────────────────────────────────────────────┐
 │ instance struct (about 1.2 KB)                     │
 │ value stack  (VALUE_STACK_SLOTS x 8 bytes)         │
 │ call frames  (CALL_DEPTH x frame size)             │
 │ module metadata + translated code                  │
 │ tables, globals, data segments                     │
 │ guest linear memory (declared size, or the cap)    │
 └────────────────────────────────────────────────────┘
```

Rule of thumb:

> arena ≈ guest memory + 8 × `VALUE_STACK_SLOTS` + about 1.4 KB + the module's translated code

## Measured sizes

Real modules from `examples/wiki/guest`, loaded on a 64-bit PC build (`eccles_wasm_get_stats().arena_used`). 32-bit chips use a little less because pointers are smaller. Default stack slots (256).

| Module | `.wasm` bytes | default memory (64 KiB) | `MEM_LIMIT_BYTES` 8 KiB | `MEM_LIMIT_BYTES` 2 KiB |
|---|---:|---:|---:|---:|
| `sensor.wasm` (ADC average) | 674 | 69,164 | 11,820 | 5,676 |
| `hello.wasm` (add, fib, printf) | 3,800 | 74,702 | 17,358 | 11,214 |
| `led.wasm` (blink, printf) | 3,929 | 74,898 | 17,554 | 11,410 |

Notes:

- The fixed cost of using `ew_printf` is about 5.5 KB of translated code. A module without it is far smaller.
- Translated code is about 1.4 times the `.wasm` size for the same functions.
- Guest memory dominates. That is why `MEM_LIMIT_BYTES` is the most important setting on small chips.

## Choosing the size

1. Start generous: `-DECCLES_WASM_ARENA_SIZE=(96ul*1024ul)`.
2. Load your real module and print the stats:

```c
eccles_wasm_stats_t s = eccles_wasm_get_stats();
printf("arena %u, used %u, guest memory %u of %u pages, code %u bytes\n",
       (unsigned)s.arena_size, (unsigned)s.arena_used, (unsigned)s.memory_bytes, (unsigned)s.memory_pages, (unsigned)s.code_bytes);
```

3. Set `ECCLES_WASM_ARENA_SIZE` to `arena_used` plus the memory the module needs to grow, plus 10 percent margin.
4. If it does not fit your chip, set `ECCLES_WASM_MEM_LIMIT_BYTES` to what the module truly touches (see below) and shrink the stack slots.

## How much guest memory does a module really use?

A stock clang module declares 64 KiB (one page) but usually touches a few hundred bytes plus its stack plus its globals. Run it with a small cap:

```bash
make ... -DECCLES_WASM_MEM_LIMIT_BYTES=2048ul
```

If it traps with `out-of-bounds memory access`, raise the cap. Also lower the guest's own stack: `-Wl,-z,stack-size=1024`. Data, bss and stack are all placed inside the capped range, so everything the guest owns must fit inside it.

## When loading fails for lack of memory

`load` fails with `out of arena memory` and `eccles_wasm_last_error_info()` gives the **bytes needed**. Raise the arena by at least that much.

## Tips per chip

| Chip RAM | Suggestion |
|---|---|
| 20 to 32 KB | 12 to 16 KB arena, `MEM_LIMIT_BYTES` 2 KB, `VALUE_STACK_SLOTS` 128, `CHUNK_SIZE` 64, no `ew_printf` in the guest |
| 64 to 128 KB | 40 KB arena, `MEM_LIMIT_BYTES` 8 KB |
| 256 KB (nRF52840, RP2040) | 96 KB arena, defaults |
| 320 KB or more (ESP32) | 96 to 128 KB arena from the heap |
| with PSRAM | put the arena there with `eccles_wasm_init_with(psram_ptr, size)`. The interpreter reads guest memory from it, so measure the speed |

Settings for the 20 to 32 KB row were measured to load and run a small module on the PC build (a 550-byte module with a 2 KB memory cap needs 5.5 KB with 256 stack slots, 4.4 KB with 128).

## Instances and threads

Each instance (and each thread child) has its own arena. Children of a threaded module share the parent's guest memory, so a child needs only its stacks and tables: 8 KB worked on an ESP32 ([Threads](Threads-and-Spawner)).

## Flash and stack

- **Flash:** about 50 KB for the runtime (`make size`), plus the modules if you embed them.
- **C stack of your calling task:** the interpreter and the loader use the stack of the task that calls them. Give that task at least 4 KB, and 8 to 16 KB on ESP32 while you measure.

# Error Reference

Two levels of result:

1. **Status** (every call): `SUCCESSFUL` 0, `FAILED` 1, `UNSUPPORTED` 2, `DENIED` 3 (guest-side only).
2. **Error** (after a `FAILED` or `UNSUPPORTED`): `eccles_wasm_last_error()` gives the detailed reason, plus `eccles_wasm_last_error_info()` (one extra number) and `eccles_wasm_last_error_str()` (an import name).

```c
if (eccles_wasm_load_buffer(app, len) != ECCLES_WASM_SUCCESSFUL) {
    printf("%s (info %u, \"%s\")\n", eccles_wasm_error_name(eccles_wasm_last_error()),
           (unsigned)eccles_wasm_last_error_info(), eccles_wasm_last_error_str());
}
```

After a successful call `last_error()` is `ECCLES_WASM_OK`.

## Statuses

| Status | Value | Seen by | Meaning |
|---|---|---|---|
| `ECCLES_WASM_SUCCESSFUL` | 0 | host and guest | done |
| `ECCLES_WASM_FAILED` | 1 | host and guest | tried and failed: bad argument, hardware error, a trap, a load error |
| `ECCLES_WASM_UNSUPPORTED` | 2 | host and guest | this chip or backend does not have it; also "no filesystem backend" |
| `ECCLES_WASM_DENIED` | 3 | guest | the host has not granted this hardware ([Permissions](Permissions)) |

## Load and API errors

| Error name (`eccles_wasm_error_name`) | Constant | `info` | Cause | Fix |
|---|---|---|---|---|
| `ok` | `ECCLES_WASM_OK` | 0 | no error | |
| `not initialised` | `ERR_NOT_INIT` | | reserved, load auto-initialises | |
| `no module loaded` | `ERR_NOT_LOADED` | | `call` or `run` before a successful load, or after unload | load first; check the load result |
| `busy (re-entrant call)` | `ERR_BUSY` | | `call` on an instance that is already running (from a host function, or from a second task) | one task per instance; never call into the same instance from its own host function |
| `out of arena memory` | `ERR_NO_MEMORY` | bytes needed | the arena is too small for this module | raise `ECCLES_WASM_ARENA_SIZE` by `info` or more; or `MEM_LIMIT_BYTES` ([Memory Sizing](Memory-Sizing)) |
| `module exceeds a configured limit` | `ERR_LIMIT` | | more blocks, locals, tables or other items than a configured limit allows | raise `MAX_CTL`, `VALUE_STACK_SLOTS` or simplify the module; build it with `-Oz` |
| `I/O error` | `ERR_IO` | | file not found, file system not mounted, or the stream/`read` callback failed | check the path, mount, and that your `open` returns non-NULL ([Custom Filesystems](Custom-Filesystems)) |
| `no filesystem backend` | `ERR_NO_FS` | | `load(path)` on a platform with no file backend and no `set_fs` | use `load_buffer`, or `set_fs` |
| `malformed module` | `ERR_MALFORMED` | byte offset | not a wasm file, truncated, or corrupt | check the file (`xxd app.wasm | head`: it starts `00 61 73 6d 01 00 00 00`); regenerate the C array; check the download length |
| `unsupported WebAssembly feature` | `ERR_UNSUPPORTED_FEATURE` | opcode or section | valid wasm using something this build does not run: SIMD, atomics (when `ATOMICS` is off), exceptions, GC, multiple memories, 64-bit memory, floats (when `NO_FLOAT`) | rebuild the guest without it, or enable the feature in the runtime ([Supported WebAssembly](FAQ#which-webassembly-features-are-supported)) |
| `unresolved import` | `ERR_IMPORT` | | the module imports a function you did not register, or an unknown `env` name. The name is in `last_error_str()` | register it before loading ([Host Functions](Host-Functions)), fix the spelling, or rebuild the guest without it |
| `signature mismatch` | `ERR_SIGNATURE` | | the registered signature string differs from the module's import type | fix the string (`"i(ii)"`), see [Host Functions](Host-Functions#the-signature-string) |
| `no such export` | `ERR_NO_EXPORT` | | the name passed to `call` is not exported | export it (`EW_EXPORT` or `--export-all`); check spelling and that `static` functions are not exported |
| `bad argument` | `ERR_BAD_ARG` | | `NULL` path, wrong `nargs`, bad pointer | pass the right number of arguments (`nargs` must equal the function's parameter count) |

## Traps (run time)

A trap ends the current call; the instance stays loaded.

| Error name | Constant | Typical cause | Fix |
|---|---|---|---|
| `trap: unreachable` | `TRAP_UNREACHABLE` | `__builtin_trap`, panic, `abort`, the end of a function that should not be reached | fix the guest; read the guest's own log before it |
| `trap: out-of-bounds memory access` | `TRAP_MEM_OOB` | wild pointer, NULL plus offset, buffer overflow, stack overflow, `MEM_LIMIT_BYTES` too small | fix the guest; raise `MEM_LIMIT_BYTES`; raise the guest's `stack-size` |
| `trap: integer divide by zero` | `TRAP_DIV_ZERO` | `x / 0` or `x % 0` | check the divisor in the guest |
| `trap: integer overflow` | `TRAP_INT_OVERFLOW` | `INT_MIN / -1` | guard in the guest |
| `trap: invalid conversion to integer` | `TRAP_BAD_CONVERSION` | float NaN or out of range converted to int | clamp first, or compile with `-mnontrapping-fptoint` |
| `trap: undefined table element` | `TRAP_UNDEFINED_ELEMENT` | calling a NULL function pointer | initialise function pointers |
| `trap: indirect call type mismatch` | `TRAP_INDIRECT_TYPE` | function pointer cast to a wrong type | fix the cast |
| `trap: value stack overflow` | `TRAP_STACK_OVERFLOW` | the operand stack is exhausted by deep expressions or many locals | raise `ECCLES_WASM_VALUE_STACK_SLOTS` |
| `trap: call stack overflow` | `TRAP_CALL_DEPTH` | recursion deeper than `CALL_DEPTH` | raise `ECCLES_WASM_CALL_DEPTH`, or iterate |
| `trap: instruction budget exhausted` | `TRAP_FUEL` | the call used its whole fuel budget | raise `set_fuel`, or fix an endless loop; `set_fuel(0)` for unlimited |
| `trap: host function failed` | `TRAP_HOST` | one of your host functions returned something other than `SUCCESSFUL` | return `SUCCESSFUL`, or treat the trap as the intended refusal |
| `trap: out-of-bounds table access` | `TRAP_TABLE_OOB` | `table.get`, `set`, `copy`, `init`, `fill` out of range | fix the index |
| `trap: unaligned atomic access or wait on unshared memory` | `TRAP_ATOMIC` | misaligned atomic address, or `wait` on non-shared memory | align the data; declare the memory shared ([Atomics](Atomics)) |

## Statuses returned to the guest by each hardware call

| Result | Reason |
|---|---|
| 3 `DENIED` | the permission, pin, bus or I2C address is not allowed |
| 2 `UNSUPPORTED` | the backend does not implement it ([capability table](Platforms-Overview)). Add it with a [HAL override](Platform-Other-MCUs) |
| 1 `FAILED` | invalid pin or bus number for the chip, driver error, bus error (no I2C acknowledge), bad mode or length |
| 0 `OK` | done |

# Troubleshooting

Find your symptom, read the cause, apply the fix. For a specific error name see [Error Reference](Error-Reference). To start from scratch use the [Bring-Up Checklist](Bring-Up-Checklist).

First, always print the reason:

```c
printf("%s (info %u, \"%s\")\n", eccles_wasm_error_name(eccles_wasm_last_error()),
       (unsigned)eccles_wasm_last_error_info(), eccles_wasm_last_error_str());
```

## The module runs but nothing happens

| Symptom | Cause | Fix |
|---|---|---|
| LED never changes, calls return 3 | deny-by-default: no privilege granted | `eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_PIN_ALL | ECCLES_WASM_ALLOW_SAFE);` |
| `eccles_wasm_denied_count()` is not 0 | something was refused | print `eccles_wasm_last_denied()` for the name, and grant that permission ([Permissions](Permissions)) |
| `ew_printf` prints nothing | needs `PERM_LOG`, and a console backend | grant `ALLOW_SAFE`; Arduino: `eccles_wasm_use_serial(Serial)`; STM32: add a `log` [HAL override](Platform-Other-MCUs) |
| `sleep` returns immediately, the loop spins | `PERM_TIME` is missing | grant it (in `ALLOW_SAFE`) |
| calls return 2 | the backend lacks the feature | check the [capability table](Platforms-Overview); add a [HAL override](Platform-Other-MCUs) |
| calls return 1 | the pin or bus number is invalid for this chip | check [pin numbering](Platforms-Overview#pin-numbering) |
| `setup` ran, but `loop` never runs | your firmware must call `eccles_wasm_run("loop")` itself; the runtime does not schedule anything | call it from your `loop()` or a task |
| the pin changes but the LED does not | wrong pin, or active-low LED | flip the level; check the board's LED pin |
| works on the PC, not on the chip | the chip backend lacks a function the simulator has | compare with the capability table |

## Loading fails

| Symptom | Cause | Fix |
|---|---|---|
| `out of arena memory` | arena too small; `info` says how many bytes were needed | raise `ECCLES_WASM_ARENA_SIZE`, set `MEM_LIMIT_BYTES`, link the guest with `-z stack-size=1024` ([Memory Sizing](Memory-Sizing)) |
| `out of arena memory` on ESP32 although heap is free | no contiguous block of that size (heap is fragmented, WiFi/BT running) | allocate before WiFi starts, use `eccles_wasm_init_with()` with a static buffer or PSRAM, or shrink the arena |
| `malformed module` | corrupt, truncated or wrong file; a text file; a file opened in text mode | regenerate the array; open files as `"rb"`; check the size; a valid file starts `00 61 73 6d` |
| `malformed module` after `load_stream` | the read callback returned 0 too early | return 0 only at the end of data |
| `unsupported WebAssembly feature` | the module uses SIMD, exceptions, atomics (without `ATOMICS`), memory64, GC | rebuild the guest without it; check clang flags (`-msimd128` and `-pthread` turn features on) |
| `unresolved import`, name in the string | a host function is not registered, or a typo, or the module uses `wasi_snapshot_preview1` calls that are not built in | register before load; the supported WASI calls are listed in [Guest Imports](Guest-Import-Reference#wasi-when-eccles_wasm_wasi-is-1-the-default) |
| `signature mismatch` | the registered type string does not match the guest's declaration | fix the string, [rules](Host-Functions#the-signature-string) |
| `I/O error` | file not found, not mounted, or the callback returned an error | check the path (LittleFS `"/app.wasm"`, FatFs `"0:/app.wasm"`) and the mount |
| `no filesystem backend` | this platform has no file system hook | `load_buffer`, or [`set_fs`](Custom-Filesystems) |
| `module exceeds a configured limit` | a limit like `MAX_CTL` was hit | raise it; compile the guest with `-Oz` |
| load works, but the module does not start | the start function trapped | `-DECCLES_WASM_AUTORUN_START=0` to separate load from start |

## Crashes and resets

| Symptom | Cause | Fix |
|---|---|---|
| the chip resets or hangs on the first call | your task's C stack is too small | give the calling task 4 KB at least; ESP-IDF `CONFIG_ESP_MAIN_TASK_STACK_SIZE=16384` while measuring |
| garbage, then a crash, only with some settings | `eccles_wasm.c` and your code see different `ECCLES_WASM_*` macros | define them with `-D` for the whole build, or put one `eccles_wasm_config.h` on the include path of both |
| watchdog reset in a long guest loop | the guest never yields | set `eccles_wasm_set_fuel(n)`, define `ECCLES_WASM_YIELD()` to feed the watchdog, or call `ew_yield()` / `ew_sleep()` in the loop |
| hard fault in `w_exec` with `EXEC_IRAM` | the loop is in RAM but the chip's linker script has no place for it (`.RamFunc`), or flash is erased while it runs | add the section to the linker script, or turn `EXEC_IRAM` off |
| stack overflow in a thread child | the RTOS task stack is too small | 4 to 8 KB; see [Threads](Threads-and-Spawner#rules) |
| the guest crashes with `out-of-bounds memory access` right away | `MEM_LIMIT_BYTES` is smaller than the guest's stack plus data | raise it, or shrink the guest's stack |
| random crashes after changing a setting | stale object files | clean build (`rm -rf .pio build`) |

## Speed

| Symptom | Fix |
|---|---|
| slower than the benchmarks | check `-O2`/`-Os` is on for `eccles_wasm.c`; set `FUEL=0`; `EXEC_IRAM=1` on ESP32 and Pico ([Speed Tuning](Speed-Tuning)) |
| `sleep` is longer than asked | the RTOS tick is coarse: on ESP32 with a 10 ms tick `sleep(25)` returns after 20 ms ([Validation](Validation)); use `sleep_us` or raise `CONFIG_FREERTOS_HZ` |
| `micros()` repeats | it wraps every 71 minutes (32 bits) |

## Build problems

| Symptom | Fix |
|---|---|
| `eccles_wasm.h: No such file` | add `src/` to the include path |
| undefined reference to `sqrt`, `sqrtf`, `fmod` | link `-lm`, or `-DECCLES_WASM_NO_FLOAT` |
| `8/16-bit MCU - a wasm instance needs tens of KB` | set `ECCLES_WASM_ARENA_SIZE` (external RAM) |
| `region 'RAM' overflowed` | arena too big for a static array: lower it, or use the heap (`ECCLES_WASM_USE_HEAP=1`) |
| `error: 'computed goto'` or label-address warnings with a strict compiler | `-DECCLES_WASM_NO_COMPUTED_GOTO` |
| STM32: `ECCLES_WASM_STM32_UART_HANDLES` undeclared | define the handles in `eccles_wasm_config.h` ([STM32](Platform-STM32)) |
| ESP-IDF: warnings as errors in the component | `target_compile_options(${COMPONENT_LIB} PRIVATE -Wno-error)` |
| the wrong backend is selected | `-DECCLES_WASM_PLATFORM=ECCLES_WASM_PLAT_...` |

## Guest build problems

| Symptom | Fix |
|---|---|
| `wasm-ld: error: unknown argument` | install `lld`: `wasm-ld --version` |
| `clang: error: unknown target 'wasm32'` | install a clang built with the WebAssembly target (`clang --print-targets | grep wasm`) |
| `undefined symbol: printf`, `memcpy`, `malloc` | `-nostdlib` has no libc: use `ew_printf` and static buffers (or `__builtin_memcpy`, or wasi-sdk) |
| the guest is 60 KB or more | do not pull in libc; use `-Oz`; look for `printf`-family calls |
| the guest uses too much memory | `-Wl,-z,stack-size=1024`, `--initial-memory=65536` |
| linker: `__stack_pointer` undefined in a threaded guest | add `.globaltype __stack_pointer, i32` to the inline asm as in `examples/wiki/guest/threads.c` |

## Blink an LED and see the status

Guest: drives pin 2 and reports exactly what the host answered.

```c
/* led.c - drive a pin, and report exactly what the host answered (0 ok, 1 failed, 2 unsupported, 3 denied). */
#include "eccles_wasm_runtime.h"

#define LED 2

EW_EXPORT("led_on")  int led_on(void)  { return ew_enable(LED); }
EW_EXPORT("led_off") int led_off(void) { return ew_disable(LED); }

EW_EXPORT("blink") int blink(int times) {
    int st = ew_pin_mode(LED, EW_OUTPUT);
    for (int i = 0; i < times && st == EW_OK; i++) {
        st = ew_enable(LED);
        if (st == EW_OK) { ew_sleep(100); st = ew_disable(LED); }
        if (st == EW_OK) ew_sleep(100);
    }
    ew_printf("blink finished with status %d (%s)\n", st, ew_status_name(st));
    return st;
}
```
*(file: `examples/wiki/guest/led.c`)*

Host, with four policies (nothing, GPIO write, pins 5 and 6 only, everything):

```c
/* 02_privileges.c - deny by default. The same module, four different policies. */
#include "eccles_wasm.h"
#include <stdio.h>

static void audit(eccles_wasm_vm_t *vm, const char *import_name) {      /* called for every refused call */
    (void)vm;
    printf("   [audit] refused: %s\n", import_name);
}

int main(int argc, char **argv) {
    const char *path = argc > 1 ? argv[1] : "build/wiki/led.wasm";
    eccles_wasm_vm_t *vm = eccles_wasm_default_vm();
    uint64_t r[1];

    eccles_wasm_vm_set_denied_hook(vm, audit);
    eccles_wasm_load(path);

    puts("1) default policy (nothing granted):");
    eccles_wasm_call("led_on", NULL, 0, r, 1);
    printf("   led_on() returned %d (3 = DENIED); pin 2 level = %u\n", (int)r[0], (unsigned)eccles_wasm_sim_pin_level(2));

    puts("2) grant GPIO write:");
    eccles_wasm_set_hal_privilege(ECCLES_WASM_PERM_GPIO_WRITE);
    eccles_wasm_call("led_on", NULL, 0, r, 1);
    printf("   led_on() returned %d (0 = OK);     pin 2 level = %u\n", (int)r[0], (unsigned)eccles_wasm_sim_pin_level(2));

    puts("3) only pin 5 and 6 may be used:");
    eccles_wasm_privilege_t p;
    eccles_wasm_privilege_init(&p, ECCLES_WASM_PERM_GPIO_WRITE);
    eccles_wasm_privilege_allow_pin_range(&p, 5, 6);
    eccles_wasm_set_privilege(&p);
    eccles_wasm_call("led_off", NULL, 0, r, 1);
    printf("   led_off() on pin 2 returned %d (3 = DENIED)\n", (int)r[0]);

    puts("4) everything:");
    eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_ALL);
    eccles_wasm_call("led_off", NULL, 0, r, 1);
    printf("   led_off() returned %d (0 = OK)\n", (int)r[0]);

    printf("refused calls so far: %u, last refused: %s\n", (unsigned)eccles_wasm_denied_count(), eccles_wasm_last_denied());
    return 0;
}
```
*(file: `examples/wiki/host/02_privileges.c`)*

```text
1) default policy (nothing granted):
   [audit] refused: enable
   led_on() returned 3 (3 = DENIED); pin 2 level = 0
2) grant GPIO write:
   led_on() returned 0 (0 = OK);     pin 2 level = 1
3) only pin 5 and 6 may be used:
   [audit] refused: disable
   led_off() on pin 2 returned 3 (3 = DENIED)
4) everything:
   led_off() returned 0 (0 = OK)
refused calls so far: 2, last refused: disable
```

## Read sensors: ADC and I2C

```c
/* sensor.c - average several ADC readings and scale them. Runs unchanged on every chip; a chip without ADC just reports 2. */
#include "eccles_wasm_runtime.h"

EW_EXPORT("read_avg") int read_avg(int pin, int samples) {
    uint32_t sum = 0, v = 0;
    for (int i = 0; i < samples; i++) {
        int st = ew_adc(pin, &v);
        if (st != EW_OK) return -st;          /* -1 failed, -2 unsupported, -3 denied */
        sum += v;
        ew_sleep(1);
    }
    return (int)(sum / (uint32_t)samples);
}
```
*(file: `examples/wiki/guest/sensor.c`)*

```c
/* i2c_temp.c - read a 16-bit register from an I2C sensor at address 0x48 (a TMP102-style part). */
#include "eccles_wasm_runtime.h"

#define SENSOR 0x48

EW_EXPORT("start") int start(int sda, int scl) { return ew_i2c_begin(0, sda, scl, 400000); }   /* ESP-IDF and Pico need real pin numbers */

EW_EXPORT("read_raw") int read_raw(void) {
    uint8_t reg = 0, rx[2] = { 0, 0 };
    int st = ew_i2c_write_read(0, SENSOR, &reg, 1, rx, 2);
    if (st != EW_OK) return -st;
    return ((rx[0] << 8) | rx[1]) >> 4;       /* 12-bit result */
}
```
*(file: `examples/wiki/guest/i2c_temp.c`)*

```c
/* 03_sensors.c - ADC and I2C from a guest, on the desktop simulator (the same code runs on a real chip). */
#include "eccles_wasm.h"
#include <stdio.h>

int main(int argc, char **argv) {
    const char *dir = argc > 1 ? argv[1] : "build/wiki";
    char path[256]; uint64_t a[2], r[1];

    /* ---- ADC ---- */
    snprintf(path, sizeof path, "%s/sensor.wasm", dir);
    eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_READ_ONLY);              /* read pins + ADC + time */
    eccles_wasm_sim_set_adc(34, 2048);                                       /* simulator only: what the pin "measures" */
    if (eccles_wasm_load(path) != ECCLES_WASM_SUCCESSFUL) return 1;
    a[0] = 34; a[1] = 8;
    eccles_wasm_call("read_avg", a, 2, r, 1);
    printf("average of 8 ADC reads on pin 34 = %d\n", (int)eccles_wasm_to_i32(r[0]));

    eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_SAFE);                   /* take the ADC away */
    eccles_wasm_call("read_avg", a, 2, r, 1);
    printf("without the ADC permission it returns %d (-3 = DENIED)\n", (int)eccles_wasm_to_i32(r[0]));

    /* ---- I2C ---- */
    snprintf(path, sizeof path, "%s/i2c_temp.wasm", dir);
    eccles_wasm_privilege_t p;
    eccles_wasm_privilege_init(&p, ECCLES_WASM_PERM_I2C);
    eccles_wasm_privilege_allow_bus(&p, ECCLES_WASM_BUS_I2C, 0);             /* only I2C bus 0 */
    eccles_wasm_privilege_allow_i2c_addr(&p, 0x48, 0x4B);                    /* only the temperature chips */
    eccles_wasm_set_privilege(&p);
    if (eccles_wasm_load(path) != ECCLES_WASM_SUCCESSFUL) return 1;
    const uint8_t reply[2] = { 0x19, 0x00 };                                 /* the "sensor" answers 0x1900 */
    eccles_wasm_sim_i2c_set_response(0, reply, 2);
    a[0] = 21; a[1] = 22;                                                    /* SDA, SCL */
    eccles_wasm_call("start", a, 2, r, 1);
    eccles_wasm_call("read_raw", NULL, 0, r, 1);
    printf("TMP102-style raw reading = %d (0x%03X)\n", (int)eccles_wasm_to_i32(r[0]), (unsigned)eccles_wasm_to_i32(r[0]));
    printf("the guest wrote to address 0x%02X\n", (unsigned)eccles_wasm_sim_i2c_last_addr(0));
    return 0;
}
```
*(file: `examples/wiki/host/03_sensors.c`)*

```text
average of 8 ADC reads on pin 34 = 2048
without the ADC permission it returns -3 (-3 = DENIED)
TMP102-style raw reading = 400 (0x190)
the guest wrote to address 0x48
```

On a real board replace the simulator calls: delete `eccles_wasm_sim_*` and pass your real pin numbers (SDA, SCL for `start`).

## Count button presses with a pin interrupt

```c
/* button.c - count button presses with a pin interrupt, report them without busy-polling the pin. */
#include "eccles_wasm_runtime.h"

#define BUTTON 0

EW_EXPORT("setup") int setup(void) {
    int st = ew_pin_mode(BUTTON, EW_INPUT_PULLUP);
    if (st == EW_OK) st = ew_irq_attach(BUTTON, EW_FALLING);
    return st;
}

EW_EXPORT("presses") int presses(void) {
    uint32_t n = 0;
    if (ew_irq_count(BUTTON, &n) != EW_OK) return -1;
    ew_irq_clear(BUTTON);
    return (int)n;
}
```
*(file: `examples/wiki/guest/button.c`)*

## Echo a UART

```c
/* uart_echo.c - read whatever arrives on UART 1 and send it back in upper case. */
#include "eccles_wasm_runtime.h"

EW_EXPORT("start") int start(int tx, int rx) { return ew_uart_begin(1, 115200, tx, rx); }

EW_EXPORT("echo_once") int echo_once(void) {
    uint8_t buf[32];
    uint32_t got = 0;
    int st = ew_uart_read(1, buf, sizeof buf, 10, &got);       /* wait up to 10 ms */
    if (st != EW_OK) return -st;
    for (uint32_t i = 0; i < got; i++) if (buf[i] >= 'a' && buf[i] <= 'z') buf[i] -= 32;
    if (got) ew_uart_write(1, buf, got);
    return (int)got;
}
```

## Stop or swap a running main

If your module uses the `main` style, the host stops it with a flag the module checks. The guest imports one host function, `host_should_stop`, and leaves its loop when it returns 1:

```c
/* main_loop.c - one entry point that loops inside the module until the host asks it to stop. */
#include "eccles_wasm_runtime.h"

EW_IMPORT("host_should_stop") int host_should_stop(void);     /* your own host function */

EW_EXPORT("main") int app_main(void) {
    int iterations = 0;
    ew_enable(2);
    while (!host_should_stop()) {
        ew_toggle(2);
        ew_sleep(100);
        iterations++;
    }
    return iterations;                                        /* the host reads this from call() */
}
```
*(file: `examples/wiki/guest/main_loop.c`)*

The host registers that function, runs `main` in its own task, and sets the flag when it wants the module to finish:

```c
/* 11_main_loop.c - run main() once in its own thread (an RTOS task on a chip) and stop it from outside. */
#define _POSIX_C_SOURCE 200809L
#include "eccles_wasm.h"
#include <pthread.h>
#include <stdio.h>
#include <time.h>

static volatile int g_stop;

static eccles_wasm_status_t host_should_stop(eccles_wasm_vm_t *vm, uint64_t *slots) {
    (void)vm;
    slots[0] = eccles_wasm_from_i32(g_stop);                  /* 1 = leave the loop */
    return ECCLES_WASM_SUCCESSFUL;
}

static void *run_module(void *arg) {                          /* the body of the task */
    uint64_t result[1];
    (void)arg;
    if (eccles_wasm_call("main", NULL, 0, result, 1) == ECCLES_WASM_SUCCESSFUL)
        printf("main returned after %s iterations\n", eccles_wasm_to_i32(result[0]) > 0 ? "many" : "no");
    else
        printf("main failed: %s\n", eccles_wasm_error_name(eccles_wasm_last_error()));
    return NULL;
}

int main(int argc, char **argv) {
    pthread_t task;
    eccles_wasm_set_hal_privilege(ECCLES_WASM_PERM_GPIO_WRITE | ECCLES_WASM_PERM_TIME);
    eccles_wasm_register("host_should_stop", host_should_stop, "i()");   /* before load */
    eccles_wasm_set_fuel(0);                                             /* main runs until it is told to stop */
    if (eccles_wasm_load(argc > 1 ? argv[1] : "build/wiki/main_loop.wasm") != ECCLES_WASM_SUCCESSFUL) {
        printf("load failed: %s\n", eccles_wasm_error_name(eccles_wasm_last_error()));
        return 1;
    }
    pthread_create(&task, NULL, run_module, NULL);
    { struct timespec ms50 = {0, 50 * 1000 * 1000}; nanosleep(&ms50, NULL); }   /* the rest of the firmware does other work */
    g_stop = 1;                                                  /* ask main to finish */
    pthread_join(task, NULL);
    puts("module stopped cleanly");
    return 0;
}
```
*(file: `examples/wiki/host/11_main_loop.c`)*

Output:

```text
main returned after many iterations
module stopped cleanly
```

To swap modules: set the flag, wait for the task to end, then `eccles_wasm_unload()` and load the new module (see "Replace the module while the firmware runs" below). With the `setup`/`loop` style none of this is needed, because the host simply stops calling `loop`.

## How the benchmark was run

- **Chip:** ESP32 rev 3.1 at 160 MHz, ESP-IDF 5.1.2 (PlatformIO `espressif32@6.5.0`), `-O2` and `CONFIG_COMPILER_OPTIMIZATION_PERF=y`.
- **Module:** `bench2.wasm`, 19,489 bytes, built with `clang --target=wasm32` from one C source that is also compiled natively.
- **Kernels:** 35 micro-benchmarks (i32, i64, f32, f64 add/mul/div/shift/bit-count/sqrt, conversions, memory access patterns, `memory.fill`/`memory.copy`, direct and indirect calls, recursion, `br_table`, locals, nested loops) plus 8 heavy kernels (`i64mix`, `crc32`, `divrem`, `imatmul`, `sieve`, `sort`, `f64`, `f32`).
- **Fairness:** each kernel is a dependent chain with no undefined behaviour and returns a 64-bit checksum. Floating point is built without fused multiply-add on both sides so results are bit-exact. Each kernel is calibrated to about 300 ms; best of 2 runs.
- **Eccles WASM build:** `ECCLES_WASM_FUEL 0` (no per-call instruction budget, the fastest loop), `ECCLES_WASM_YIELD_INTERVAL 0`, with the interpreter loop running from internal RAM (IRAM). In the release source that is `ECCLES_WASM_EXEC_IRAM 1`.
- **wasm3 build:** its hot operations are also placed in IRAM.
- The raw log is [`validation/02-benchmark-vs-wasm3/logs/run-2026-11-14.log`](https://github.com/igwe-starking/eccles-wasm/blob/main/validation/02-benchmark-vs-wasm3/logs/run-2026-11-14.log) and the firmware that produced it is in the same folder.

## Reading the numbers honestly

- **wasm3's simple i32 loops ran at about 80x native**, well above its usual range, so treat wasm3's numbers as a lower bound on what wasm3 can do on this chip.
- **On a PC (x86) the order was reversed:** wasm3 was 1.4x faster than Eccles WASM there. The two interpreters behave very differently on the Xtensa core, so do not carry x86 numbers over to your chip, and measure on yours.
- **f64 looks almost free** (1.1x to 1.8x) because the ESP32 has no double-precision hardware: native code also runs doubles in software.
- **`mem_bulk` is under 1.0x** for both interpreters: `memory.fill` and `memory.copy` execute as one operation, while the native `memset`/`memcpy` loop is slower on this chip.
- The default build (`FUEL 1`) is a little slower than the benchmark build. Set `ECCLES_WASM_FUEL 1` and measure if you need that number.

## What this means for your project

A 10x slowdown versus native code is still plenty for the work a plugin does on a microcontroller: reading sensors, applying thresholds, running a control loop at tens of Hz, parsing a protocol, driving a state machine. A CRC-32 kernel over a buffer ran in about 17 times the native time; native takes 17.6 ms for that work, so the interpreter takes about 0.3 s. Put heavy inner loops (FFT, large DSP, crypto) in native C and call them as [host functions](Host-Functions); keep the logic in WebAssembly.

## Measure on your own chip

The benchmark firmware is a PlatformIO project: open `validation/02-benchmark-vs-wasm3/firmware/` in VS Code with PlatformIO, delete `.pio` and `sdkconfig.esp32dev`, build, upload, and open the monitor at 115200. It runs for 2 to 4 minutes and stops by itself. Tune with `-DBENCH_TARGET_MS=300 -DBENCH_REPEATS=2` in `build_flags`. See [Validation](Validation) and [Speed Tuning](Speed-Tuning).

# Validation

Eccles WASM v2.0 was run on a **physical ESP32** (rev 3.1, ESP-IDF 5.1.2) through a conformance suite of about 4200 checks. Every check prints `got | expect`, and the firmware stops by itself after about 80 seconds.

```
guest-module checks : PASS=1031 FAIL=0 INFO=41 UNSUPPORTED=2 SKIPPED=2
main.c checks       : PASS=3155 FAIL=0 INFO=18 SKIPPED=0
sections aborted=0, modules that failed to load=0
TOTAL PASS=4186  FAIL=0
```

The full serial log is [`validation/01-conformance-suite/logs/run-2026-11-14.log`](https://github.com/igwe-starking/eccles-wasm/blob/main/validation/01-conformance-suite/logs/run-2026-11-14.log).

## The nine phases

| Phase | What it checks |
|---|---|
| A Regression | 9 guest modules: hardware (GPIO, PWM, IRQ, ADC, UART, I2C, SPI), timing, i32/i64/f32/f64 edge arithmetic, SHA/ChaCha/primes, conversions |
| B Traps | 16 deliberate traps with exact trap codes and instance recovery; 504 raw float-to-int opcode cases |
| C Privileges | Deny-by-default permissions: 51 policies x 44 imports x argument variants against an independent model; pin, bus and I2C-address allow-lists; the denied hook; WASI errno 76; denied calls leave the hardware untouched |
| D Edge cases | 399 table cases on 51 hand-assembled modules: control flow, bulk memory, tables, globals, NaN payloads, limits, malformed modules |
| E Atomics | All 1960 threads-proposal opcode cases, alignment and bounds traps, wait/notify, shared and unshared memory |
| F Robustness | Truncation sweep and deterministic mutation fuzzing. The chip must never crash |
| G Speed | 8 kernels, native versus WebAssembly, bit-identical results |
| H Threads | Sibling instances on FreeRTOS tasks over one shared memory (both cores), spawn limits, trap isolation, per-thread privileges |
| I Instances | Isolation, concurrent instances, create/destroy leak check, arena sizing |

## Reading the log

- `PASS` and `FAIL` are checks with a known right answer.
- `INFO` means the check needs a jumper wire or an attached device, or it is a measurement. They are not failures.
- `UNSUP` means the chip or backend cannot do it (there is no DAC backend and no I2S import).
- `SKIP` means `reset()` and `deep_sleep()` are deliberately not run.

**One line to know about.** Line 5221 shows `[FAIL] every thread measured >= 24 ms for sleep(25)`. The ESP32 FreeRTOS tick is 10 ms, so `sleep(25)` returned after 20 ms, and this guest check (written to require 24 ms) did not allow that. It comes from the thread section's own counters and is not part of the grand total. Everything else passed.

## Optional jumpers

Checks marked `INFO` use these wires. Without them the suite still runs and still reports no failures.

| Wire | For |
|---|---|
| GPIO26 to GPIO27 | PWM and pin interrupts |
| GPIO17 to GPIO16 | UART2 loopback |
| GPIO23 to GPIO19 (SCK on 18) | SPI loopback |
| GPIO21 and GPIO22 with pull-ups | I2C |

## What ran where

The firmware folders contain the runtime copy that was compiled into each firmware: an earlier snapshot of the release with the same public API. Its version string still reads 1.0.0. For the conformance run it differs from `src/` only in comments, the version string and the optional `ECCLES_WASM_EXEC_IRAM` setting (off by default), so it behaves like the release. The benchmark keeps the interpreter loop in IRAM with a hand-written attribute that the release now offers as `ECCLES_WASM_EXEC_IRAM`. That option also moves the dispatch table to internal RAM, so numbers from the release source may differ slightly. The release in the repository root is checked by its own host test suite (`make check`, `make wasm-threads`, differential fuzzing against Node's WebAssembly engine; see [Testing and Contributing](Testing-and-Contributing)). To refresh the hardware numbers with the release source, copy `src/eccles_wasm.c` and `src/eccles_wasm.h` over the firmware's copies (for the benchmark also set `ECCLES_WASM_EXEC_IRAM` to 1 in its `eccles_wasm_config.h`) and re-flash.

Each firmware folder is the project exactly as it was built for the log beside it. Nothing was changed afterwards.

See also: [Performance and Benchmarks](Performance-and-Benchmarks).

# Speed Tuning

Defaults are chosen for safety. These settings trade some of that safety, or some RAM, for speed. Change one at a time and measure on your chip.

## The settings, fastest gain first

| Setting | Effect | Cost |
|---|---|---|
| Compile `eccles_wasm.c` with `-O2` (or the PlatformIO/ESP-IDF performance preset) | Biggest single gain over `-Os` | Larger flash |
| `ECCLES_WASM_FUEL 0` | Removes the per-instruction budget check from the loop | `eccles_wasm_set_fuel()` no longer limits runaway code; stop a stuck call with the task watchdog instead |
| `ECCLES_WASM_EXEC_IRAM 1` | Runs the interpreter loop from internal RAM on ESP32, Pico, STM32 and Zephyr | A few KB of RAM; on ESP32 it keeps running while the flash cache is off |
| `ECCLES_WASM_YIELD_INTERVAL 0` | No periodic yield call in loops and calls (`YIELD_INTERVAL` needs `FUEL 1`, so with `FUEL 0` it must be 0) | The interpreter never feeds a watchdog or lets other tasks run by itself |
| Computed goto (automatic on GCC and Clang) | Faster dispatch | None. Leave it on; `ECCLES_WASM_NO_COMPUTED_GOTO` turns it off |
| `ECCLES_WASM_NO_FLOAT` | Smaller code | Modules that use floats are rejected |

The benchmark build on the [Performance and Benchmarks](Performance-and-Benchmarks) page used `-O2`, `FUEL 0`, `YIELD_INTERVAL 0` and the loop in IRAM.

## ESP32 example

`eccles_wasm_config.h`:

```c
#define ECCLES_WASM_FUEL            0
#define ECCLES_WASM_YIELD_INTERVAL  0
#define ECCLES_WASM_EXEC_IRAM       1
```

`sdkconfig.defaults` (ESP-IDF):

```
CONFIG_COMPILER_OPTIMIZATION_PERF=y
```

With `YIELD_INTERVAL 0` and `FUEL 0`, a guest that never returns will starve the task watchdog. Run the guest in its own task and keep a hard limit another way (see [Safety, Fuel and Traps](Safety-Fuel-and-Traps)).

## Rules of thumb

1. **Do the heavy work in C.** Move FFTs, filters, hashes and big copies into a [host function](Host-Functions). Keep decisions and glue in WebAssembly.
2. **Use bulk memory.** Guests built with `-mbulk-memory` turn `memcpy` and `memset` into single instructions that the runtime runs as one operation.
3. **Floats on chips without a double-precision FPU are not a special cost.** Native code also runs them in software, so the gap to native is small (f64 ran at 1.1x to 1.8x native on the ESP32).
4. **Keep loops tight.** Fewer locals live across a loop body means fewer memory reads in the interpreter.
5. **Build the guest with `-O2`** so the translated code is smaller and faster.

## Measure

Run the same module with and without a setting and compare the time of one call:

```c
uint32_t t0 = millis();               /* your platform's timer */
eccles_wasm_run("work");
printf("%u ms\n", (unsigned)(millis() - t0));
```

For the full benchmark, see [Validation](Validation) and the `validation/02-benchmark-vs-wasm3/` folder.

# Migrating from 1.x to 2.0

Version 2.0 has **one breaking change**: hardware access is now **deny by default**. Everything else is additive.

## What changed

| 1.x | 2.0 |
|---|---|
| A module could use any pin, bus or peripheral | A new instance can use **nothing** until you grant it |
| Hardware imports always worked | A denied import returns `DENIED` (3) to the guest and the hardware is not touched |
| One privilege model | Permission bits, pin/bus/I2C-address allow-lists, a denied hook and counters |
| No threads | Optional `ECCLES_WASM_ATOMICS` and `ECCLES_WASM_THREADS` (wasi-threads) with your own spawner |
| Files only through built-in backends | `eccles_wasm_set_fs(open, read, close)` for your own file source |

## The one-line fix

Add this after `eccles_wasm_init()` and before `eccles_wasm_load()`:

```c
eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_PIN_ALL | ECCLES_WASM_ALLOW_SAFE);
```

That gives modules every pin plus the safe peripherals (time, random, log, and so on). Add `| ECCLES_WASM_PERM_I2C` or other bits if the module needs buses. See [Permissions](Permissions) for all presets.

## Keep the 1.x behaviour for the whole build

If you trust every module and want exactly the old behaviour, change the default in `eccles_wasm_config.h`:

```c
#define ECCLES_WASM_DEFAULT_PRIVILEGE  ECCLES_WASM_ALLOW_ALL
```

Do this only when you control all the WebAssembly that runs on the device.

## Check that it worked

1. Run your app. If a pin does nothing, the module was denied.
2. Call `eccles_wasm_denied_count()` and `eccles_wasm_last_denied()` after a run to see what was refused.
3. Or install a hook with `eccles_wasm_vm_set_denied_hook()` to print each denial.

See [Troubleshooting](Troubleshooting) ("The module runs but nothing happens").

## New things you can adopt

- Narrow grants per module: allow only pins 2 and 4, only I2C address 0x48.
- Several instances with different privileges: [Instances](Instances).
- Threads: [Threads and Spawner](Threads-and-Spawner), [Atomics](Atomics).
- Load from any storage: [Custom Filesystems](Custom-Filesystems).
- Loop in internal RAM: `ECCLES_WASM_EXEC_IRAM 1` ([Speed Tuning](Speed-Tuning)).

# Testing and Contributing

## What you need

A C99 compiler (GCC or Clang), `make` and Python 3. Node 22 is needed for the differential fuzzer. clang with `wasm-ld` is needed for `make guests` and the wiki examples.

## The make targets

| Command | What it does |
|---|---|
| `make check` | Unit tests in several configurations, backend compile checks with mocks, examples, SDK check, dispatch table check |
| `make test` | Only the unit tests (default, static arena, small, no-float, atomics configurations) |
| `make mocks` | Compile-checks every hardware backend against stub headers |
| `make tsan` | Several instances on several threads under ThreadSanitizer |
| `make wasm-threads` | The wasi-threads build under TSan, plain and ASan |
| `make chaos` | Type-confused and mutated modules under ASan and UBSan |
| `make fuzz` | Differential test against Node's WebAssembly engine |
| `make guests` | Compile the C and C++ guests to `wasm32` and run them |
| `make wiki-examples` | Build and run every example used in the wiki, with real output |
| `make wiki` | Regenerate `wiki/` and `ECCLES_WASM_WIKI.txt` from `wiki-src/` |
| `make wiki-check` | Fail if the wiki is stale or a public function is undocumented |
| `make help` | List the targets |

Use `make CC=clang check` to try another compiler. The sanitizer targets need the compiler's sanitizer runtime installed.

## The wiki is generated

Edit the pages in `wiki-src/`, never in `wiki/`. The page text can pull in files and example output with markers; the list is at the top of `tools/build_wiki.py` (include a file in a code block, paste a file as it is, paste the captured output of an example from `examples/wiki/`, or paste the library version).

`make wiki-check` also checks that every public function in `src/eccles_wasm.h` appears in the wiki and that every `eccles_wasm_*` name the wiki mentions exists.

## Rules for changes

- Plain C99, no dependencies. The runtime stays two files.
- Anything a guest can influence is bounds-checked.
- New features that cost flash or RAM sit behind a config macro.
- Every behavior change comes with a test.
- After changing an opcode handler run `python3 tests/gen_dispatch.py` and commit the result.

## Adding a platform backend

1. Add a `PLAT_*` value and the pin/time/bus functions in the backend section of `src/eccles_wasm.c`, following an existing backend.
2. Add a stub header under `tests/mocks/` and a line in `make mocks`.
3. Document the pin numbering and the supported imports on a new `Platform-*` page and in [Platforms Overview](Platforms-Overview).

Or skip the library change: [Other MCUs](Platform-Other-MCUs) shows how to supply your own backend with `eccles_wasm_hal_override`.

## Reporting a bug

Open an issue with the form on GitHub. Include: the board, the backend, your `eccles_wasm_config.h`, the status code, `eccles_wasm_last_error_str()` and `eccles_wasm_last_error_info()`, and the smallest module that shows it. For security problems see `SECURITY.md`.

# FAQ

## What is Eccles WASM?

A WebAssembly runtime written in plain C99 for microcontrollers. You add two files to a project, load a `.wasm` module, and call its functions. See [Quick Start](Quick-Start).

## Which chips does it run on?

Arduino cores (AVR is too small; ARM and ESP cores work), ESP32 with ESP-IDF, Raspberry Pi Pico, STM32 HAL, Zephyr and nRF, and any other chip through the [portable backend](Platform-Other-MCUs). See [Platforms Overview](Platforms-Overview).

## How much RAM do I need?

The runtime needs about 1.4 KB fixed, plus the value stack, the guest's memory and the translated code (about 1.4 times the module size). 48 KB of arena is a comfortable start; ESP32 and Pico use 96 KB by default. See [Memory Sizing](Memory-Sizing).

## Which WebAssembly features are supported?

Supported: WebAssembly core 1.0, sign-extension operators, saturating float-to-int conversions, bulk memory, multi-value, reference types, tail calls, extended constants, mutable globals, imported memory, tables and globals, and a minimal WASI. Atomics and threads (wasi-threads) are optional (`ECCLES_WASM_ATOMICS`, `ECCLES_WASM_THREADS`).

Not supported: SIMD, exception handling, garbage collection, multiple memories and 64-bit memory. A module that needs one is rejected at load with `ERR_UNSUPPORTED_FEATURE`.

## What language can I write the guest in?

Anything that compiles to `wasm32`: C, C++, Rust, Zig, AssemblyScript. The repository ships a C SDK (`sdk/c`) and a Rust crate (`sdk/rust`). See [Writing Guests](Writing-Guests).

## Is it safe to run code I do not trust?

The sandbox checks every memory access, and hardware is denied by default, so a module can only use what you grant. A runaway loop is stopped by [fuel](Safety-Fuel-and-Traps). See [Permissions](Permissions).

## How do I give the module access to a pin?

```c
eccles_wasm_set_hal_privilege(ECCLES_WASM_ALLOW_PIN_ALL | ECCLES_WASM_ALLOW_SAFE);
```

See [Permissions](Permissions) and [Migration 1 to 2](Migration-1-to-2).

## How do I load a module from a file?

Use the built-in backend for your storage, or give the runtime your own file functions with `eccles_wasm_set_fs`. See [Loading Modules](Loading-Modules) and [Custom Filesystems](Custom-Filesystems).

## How do I run code on another thread?

Build with `ECCLES_WASM_ATOMICS` and `ECCLES_WASM_THREADS`, grant `PERM_THREADS`, and register a spawner that starts an RTOS task. See [Threads and Spawner](Threads-and-Spawner).

## How do I call my own C code from the module?

Register a host function before loading. See [Host Functions](Host-Functions).

## How fast is it?

On a real ESP32 it ran 10.4x slower than native C and about 2x faster than wasm3, with identical results on all 43 kernels. See [Performance and Benchmarks](Performance-and-Benchmarks).

## Can I make it faster?

Yes. See [Speed Tuning](Speed-Tuning).

## Is it tested on real hardware?

Yes, an ESP32 conformance run of 4186 checks passed with 0 failures. See [Validation](Validation).

## Why does a pin do nothing?

The instance was not granted the hardware. See [Troubleshooting](Troubleshooting).

## Why did loading fail?

Read the status and `eccles_wasm_last_error_str()`. See [Error Reference](Error-Reference).

## Can I run more than one module?

Yes, with instances. See [Instances](Instances).

## Does it need malloc?

No. The default is a static arena. `ECCLES_WASM_USE_HEAP 1` allocates the arena with `malloc` instead. See [Configuration Reference](Configuration-Reference).

## What is the license?

MIT.

# Glossary

| Term | Meaning |
|---|---|
| **Guest** | The WebAssembly module that runs inside the runtime |
| **Host** | Your firmware, the C program that runs the runtime |
| **Module** | A `.wasm` file: code, memory declaration, imports and exports |
| **Instance** | A loaded module with its own memory, globals, stacks and privileges (`eccles_wasm_vm_t`) |
| **Default instance** | The instance used by the functions without `vm` in the name |
| **Import** | A function the module asks the host to provide, such as `gpio_write` or your own host function |
| **Export** | A function or memory the module offers to the host, such as `blink` |
| **Host function** | A C function you register with `eccles_wasm_register` so the guest can call it |
| **Signature** | The letters after a host function name, such as `i(ii)`: result `i`, arguments `i`,`i` (`i` i32, `I` i64, `f` f32, `F` f64, `v` none) |
| **Arena** | The block of RAM the runtime uses for everything: metadata, translated code, stacks and guest memory |
| **Translation** | Load-time conversion of the module's code into the runtime's faster internal form |
| **Linear memory** | The guest's single block of bytes. It is a part of the arena |
| **Page** | 64 KiB, the unit WebAssembly uses to size memory |
| **Fuel** | A per-call instruction budget. When it runs out the call stops with a trap |
| **Trap** | A runtime error in the guest, such as out-of-bounds access, divide by zero or `unreachable`. The instance stays usable |
| **Privilege** | What an instance is allowed to do with the hardware: permission bits and allow-lists |
| **Deny by default** | A new instance has no hardware access until the host grants it |
| **Backend** | The runtime's code for one platform (Arduino, ESP-IDF, Pico, STM32 HAL, Zephyr, host) |
| **HAL override** | Supplying your own pin, time and bus functions with `eccles_wasm_hal_override` |
| **Spawner** | A function you register that starts an RTOS task or thread for `thread-spawn` |
| **wasi-threads** | The WebAssembly proposal for starting threads from a module |
| **Atomics** | Instructions for safe shared-memory access between threads |
| **Streaming loader** | Loading a module from a file or stream in small chunks, so the whole file never needs to fit in RAM |
| **IRAM** | Internal RAM that keeps executing while the flash cache is off (ESP32) |
| **WASI** | The WebAssembly System Interface; the runtime has a minimal built-in subset |
| **wasm3** | Another WebAssembly interpreter for small devices, used in the benchmark |
